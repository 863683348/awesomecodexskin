Your Codex CLI palette is the surface you stare at all day, so it deserves more thought than the default. This roundup ranks the best terminal themes for Codex CLI in 2026 — all available as installed syntax palettes — on readability, eye strain, and how well they pair with your terminal.

## How we ranked

Each theme was scored on four criteria:

1. **Contrast & readability** — foreground vs. background separation while coding.
2. **Eye strain** — glare reduction for long sessions.
3. **Terminal pairing** — whether the same palette exists as a real terminal theme.
4. **Longevity** — palettes that have stood the test of time.

## 1. Tokyo Night — best all-rounder

Tokyo Night (the low-glare dark blue palette) tops the list. Its blue-tinted dark background reduces glare compared to pure black, and the syntax colors are carefully separated, so it stays readable in both a 80-column prompt and long file listings. It has a well-known terminal and VS Code counterpart, making it the easiest to sync across your whole setup.

## 2. Monokai Stone — best for syntax highlighting

Monokai Stone is the classic choice for syntax-heavy work. Its warm, muted background keeps bright syntax colors legible without the harsh contrast of the original Monokai. If you spend your day reading diffs and code, this is the palette that will feel most "right" after a few minutes.

## 3. Solarized — best for long sessions

Solarized was designed around the *lab color space* to minimize contrast fatigue — and it still holds up. The muted retro palette is easy on the eyes for hours, and it exists as a terminal theme on every platform. The trade-off: less "pop" if you like vivid colors.

## 4. Vivid Purple — best for personality

If you want your CLI to feel less like a default and more like *yours*, Vivid Purple brings a saturated purple identity while keeping foreground contrast high enough for comfortable reading. It's a great second theme to switch to for a change of pace.

## 5. Amber Nocturne — best warm dark option

Amber Nocturne is the warm-dark pick — a soft amber-on-dark palette that's gentler on the eyes than cool blue themes in dim rooms. It pairs beautifully with an amber terminal theme for a cohesive, retro-futuristic workspace.

## How to install any of these

Every theme above installs as a Codex CLI syntax palette in one command, then applies via `/theme`:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
/theme
```

## Which should you pick?

- **Default recommendation:** Tokyo Night — best balance of readability and pairing.
- **Syntax-heavy work:** Monokai Stone.
- **All-day sessions or sensitive eyes:** Solarized.
- **Personality:** Vivid Purple or Amber Nocturne.
