Codex Skin Studio supports multiple skin engines, each with its own strengths. The three main engines are Dream Skin (GUI-based), CLI (command line), and Theme Files (codedrobe/codextheme).

## The Three Main Engines

**Dream Skin** is best for beginners — intuitive, real-time preview, drag-and-drop management.

**CLI** is best for power users — fast, scriptable, works in terminal-only environments.

**Theme Files** are best for developers — full control over every color and style token, portable across machines.

## FAQ

**Can I use Dream Skin and CLI together?** Yes. They operate on the same underlying theme system.

**Which engine produces the best-looking themes?** All three use the same rendering pipeline.
