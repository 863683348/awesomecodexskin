O projeto [Fei-Away Codex-Dream-Skin](https://github.com/Fei-Away/Codex-Dream-Skin) — um dos motores de skins do Codex mais ativos no open-source — contribuiu 7 presets de prompt para o índice esta semana. Se você tem curiosidade sobre a criação de skins baseada em prompts, este é um bom momento para dar uma olhada.

## Novidades do Fei-Away

Os sete novos presets mostram a gama do motor Dream Skin, desde looks profissionais limpos até temas totalmente estilizados:

- [Cyra Sacred Radiance](/skins/cyra-sacred-radiance/) — um tema luminoso e com inclinação para luzes claras.
- [Dasiming Soul Passage](/skins/dasiming-soul-passage/) — uma opção escura e atmosférica.
- [Jensen Infinite Compute](/skins/jensen-infinite-compute/) — uma paleta estilizada tecnológica.
- Mais quatro que cobrem o espectro entre eles.

Todos os sete são instalados pelo método Dream Skin: copie o prompt, cole no Codex, pronto. A [comparação de motores](/blog/codex-skin-engines-compared/) explica por que esse é o caminho de instalação mais rápido no ecossistema.

## Panorama geral dos motores

Além do Fei-Away, algumas coisas estão acontecendo no mundo dos motores:

- **Codepilot** continua enviando melhorias no TUI — validação e exportação de paletas são os recursos principais. Veja a [comparação do CLI](/blog/codex-themes-cli-vs-codepilot/) para ver como ele se compara.
- **Codex Themes CLI** (ychampion) continua portando clássicos da terminal; as portas Tokyo Night presentes neste índice vêm dessa linha.
- **Bearded Theme Ports** (vufly) adicionou mais importações tmtheme, o que é como temas de terminal como Tokyo Night continuam fluindo para o Codex.

## Por que os presets importam

Presets são o caminho "experimente em cinco segundos". Em vez de baixar um arquivo e configurar um motor, você cola uma frase. O tradeoff é a precisão — um prompt é uma descrição, não um especificação — o que é abordado em detalhes na [comparação de formatos](/blog/codex-theme-file-vs-prompt-preset/). Para explorar humores rapidamente, nada bate nele.

## Como testar os presets do Dream Skin

1. Abra a página de um skin de preset — [Cyra Sacred Radiance](/skins/cyra-sacred-radiance/) ou [Dasiming Soul Passage](/skins/dasiming-soul-passage/) funcionam bem.
2. Copie o prompt de instalação.
3. Cole-o no Codex com o motor Dream Skin ativo.
4. Pronto — volte para o preset padrão sempre que quiser.

O ecossistema de motores está se tornando claro: motores de prompt para velocidade, gerenciadores baseados em arquivos para precisão, ferramentas de CLI para usuários de terminal. Cada nova contribuição, como este lote do Fei-Away, torna o ecossistema um pouco mais completo. Navegue pelo [índice de skins](/skins/) para ver todos os novos presets.
