O projeto [Fei-Away Codex-Dream-Skin](https://github.com/Fei-Away/Codex-Dream-Skin) — um dos motores de skins Codex de código aberto mais ativos — contribuiu com 7 predefinições de prompt para o índice nesta semana. Se você já se interessou por personalização baseada em prompts, este é um ótimo momento para dar uma olhada.

## Novidades da Fei-Away

As sete novas predefinições demonstram a amplitude do mecanismo Dream Skin, indo de aparências limpas e profissionais até temas totalmente estilizados:

- [Cyra Sacred Radiance](/skins/cyra-sacred-radiance/) — um tema luminoso, com tendência à claridade.  
- [Dasiming Soul Passage](/skins/dasiming-soul-passage/) — uma opção escura e atmosférica.  
- [Jensen Infinite Compute](/skins/jensen-infinite-compute/) — uma paleta com estilo tecnológico.  
- Mais quatro predefinições que cobrem todo o espectro entre essas extremidades.

Todas as sete são instaladas pelo método Dream Skin: copie o prompt, cole-o no Codex — pronto! A [comparação entre mecanismos](/blog/codex-skin-engines-compared/) explica por que esse é o caminho de instalação mais rápido do ecossistema.

## Panorama mais amplo dos mecanismos

Além da Fei-Away, algumas outras coisas estão acontecendo no mundo dos mecanismos:

- **Codepilot** continua lançando melhorias na interface TUI — validação e exportação de paletas são os destaques. Confira a [comparação entre CLIs](/blog/codex-themes-cli-vs-codepilot/) para ver como ele se compara.  
- **Codex Themes CLI** (ychampion) segue migrando clássicos de terminais; as versões Tokyo Night incluídas neste índice vêm dessa linha de trabalho.  
- **Bearded Theme Ports** (vufly) adicionou mais importações no formato tmtheme, o que permite que temas de terminal como Tokyo Night continuem fluindo para o Codex.

## Por que as predefinições de prompt são importantes

Predefinições são o caminho “experimente em cinco segundos”. Em vez de baixar um arquivo e configurar um mecanismo, basta colar uma frase. A troca envolvida é precisão — um prompt é uma descrição, não uma especificação — e essa diferença é analisada em profundidade na [comparação de formatos](/blog/codex-theme-file-vs-prompt-preset/). Para explorar rapidamente diferentes estados de ânimo visuais, nada supera essa abordagem.

## Como experimentar as predefinições Dream Skin

1. Abra a página de uma predefinição — [Cyra Sacred Radiance](/skins/cyra-sacred-radiance/) ou [Dasiming Soul Passage](/skins/dasiming-soul-passage/) são boas opções.  
2. Copie o prompt de instalação.  
3. Cole-o no Codex com o mecanismo Dream Skin ativo.  
4. Pronto — volte à predefinição padrão sempre que desejar.

O ecossistema de mecanismos está se consolidando em uma estrutura clara: mecanismos baseados em prompts para velocidade, gerenciadores baseados em arquivos para precisão e ferramentas CLI para usuários de terminal. Cada nova contribuição como esse lote da Fei-Away torna o ecossistema um pouco mais completo. Navegue pelo [índice de skins](/skins/) para ver todas as novas predefinições.
