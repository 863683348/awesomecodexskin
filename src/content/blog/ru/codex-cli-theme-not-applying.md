`/theme` ничего не возвращает, цвета не меняются, или палитра выглядит неправильно? Проблемы с темами Codex CLI почти всегда связаны с одним из пяти причин. Вот как диагностировать и исправить каждую из них по порядку.

## 1. Тема не установлена (наиболее частая причина)

`/theme` отображает только те темы, которые существуют в каталоге тем Codex CLI. Если вы никогда не запускали скрипт установки, список пуст или показывает только стандартную тему.

**Решение:** сначала установите палитру:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
```

Потом перезапустите командную строку и снова выполните `/theme` — новая палитра должна появиться под своим точным названием.

## 2. Устаревший кэш цветов при запуске

Некоторые порты кэшируют цвета при запуске Codex CLI. После применения темы палитра может выглядеть неправильно до следующего запуска.

**Решение:** перезапустите Codex CLI после применения темы, затем снова выполните `/theme` с тем же именем. Если правильная палитра появилась, значит, проблема была в кэше.

## 3. Название темы не совпадает

`/theme` точно соответствует названиям тем. `Tokyo Night` не является таким же, как `tokyo-night` или `TokyoNight`.

**Решение:** выполните `/theme` без аргументов и скопируйте точное имя из списка, затем примените его буквально.

## 4. Неправильный или неполный файл палитры

Палитра, скопированная из скрипта портирования, может быть неполной — отсутствуют ключи фона, переднего плана или синтаксиса. Это проявляется как основные цвета по умолчанию с одним или двумя изменениями.

**Решение:** повторно запустите скрипт установки, чтобы получить полную тему, или используйте менеджер для проверки файла:

```bash
# Codex Themes CLI проверяет палитру перед применением:
codex-theme validate <name>
codex-theme apply <name>
```

## 5. Несоответствие терминала и CLI

Если *терминал* совпадает, но Codex CLI нет (или наоборот), то оба читают разные конфигурации. Темы CLI — это просто палитры — они не изменяют ваш профиль терминала.

**Решение:** экспортируйте одну и ту же палитру в оба. Codex Themes CLI может записать одинаковые цвета в ваш профиль терминала, поэтому одно применение синхронизирует обе поверхности:

```bash
codex-theme export <name> --to-terminal
```

## Все еще застряли?

Вернитесь к чистому состоянию: удалите палитру, перезапустите, переустановите и примените с точным именем. Если у конкретной темы возникла проблема, перейдите в категорию [Mono & Terminal](/skins/category/mono-terminal/) для последних вариантов палитр, или проверьте [руководство по темам CLI](/blog/codex-cli-themes-guide/) для полного процесса установки.
