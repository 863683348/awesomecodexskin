Команда `/theme` ничего не возвращает, цвета не меняются или палитра отображается некорректно? Проблемы с темами в Codex CLI почти всегда связаны с одной из пяти причин. Ниже приведены пошаговые инструкции по диагностике и устранению каждой из них — в порядке убывания вероятности.

## 1. Тема не установлена (самая частая причина)

Команда `/theme` отображает только те темы, которые присутствуют в директории тем Codex CLI. Если вы никогда не запускали скрипт установки, список будет пустым или покажет лишь тему по умолчанию.

**Решение:** установите палитру:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
```

Затем перезапустите терминал и снова выполните `/theme` — новая палитра должна появиться под своим точным именем.

## 2. Устаревший кеш цветов при запуске

Некоторые порты кэшируют цвета при старте Codex CLI. После применения темы палитра может отображаться некорректно до следующего запуска приложения.

**Решение:** перезапустите Codex CLI после применения темы, затем повторно выполните `/theme`, указав то же имя. Если отобразится корректная палитра — проблема была в кеше.

## 3. Имя темы не совпадает точно

Команда `/theme` выполняет строгое сравнение имён тем. `Tokyo Night` отличается от `tokyo-night` и от `TokyoNight`.

**Решение:** выполните `/theme` без аргументов, скопируйте точное имя из списка и примените его без изменений.

## 4. Неполный или некорректный файл палитры

Палитра, скопированная из скрипта портирования, может быть неполной — например, в ней могут отсутствовать ключи для фона, переднего плана или синтаксиса. В этом случае большинство цветов останутся стандартными, а изменятся лишь один-два элемента.

**Решение:** повторно запустите скрипт установки, чтобы получить полную тему, либо используйте менеджер для проверки файла:

```bash
# Codex Themes CLI проверяет палитру перед применением:
codex-theme validate <name>
codex-theme apply <name>
```

## 5. Рассогласование между терминалом и CLI

Если *терминал* отображает правильные цвета, а Codex CLI — нет (или наоборот), это означает, что они считывают разные конфигурационные файлы. Темы CLI — это просто палитры; они не влияют на профиль терминала.

**Решение:** экспортируйте одну и ту же палитру в оба места. Codex Themes CLI может записать идентичные цвета в профиль вашего терминала, поэтому одно применение синхронизирует оба интерфейса:

```bash
codex-theme export <name> --to-terminal
```

## По-прежнему не получается?

Вернитесь к чистому состоянию: удалите палитру, перезапустите приложение, установите её заново и примените, указав точное имя. Если проблема возникает с конкретной темой, просмотрите раздел [Mono & Terminal](/skins/category/mono-terminal/) для получения последних вариантов палитр или ознакомьтесь с [руководством по темам CLI](/blog/codex-cli-themes-guide/) для полного цикла установки.
