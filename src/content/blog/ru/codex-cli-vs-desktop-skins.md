Два очень разных системы оформления в Codex: **темы для Codex CLI** и **скины для Codex Desktop**. Снаружи они выглядят одинаково (оба меняют внешний вид вашей рабочей среды), но работают совершенно по-разному — и выбор правильной зависит от того, как вы используете Codex.

## Краткий вариант

- **Скины для Codex Desktop** изменяют *интерфейс приложения* — боковую панель, границы, поверхности, акцентные цвета. Они богатые, визуальные и устанавливаются через подсказку или файл темы.
- **Темы для Codex CLI** изменяют *цветовую палитру терминала* — фон, текст и цвета синтаксиса. Они лёгкие, переносимые и устанавливаются командой, применяются через `/theme`.

Если вы используете десктопное приложение, вам нужны скины для Desktop. Если вы живете в терминале, вам нужны темы для CLI.

## Что каждая система меняет

| Аспект | Скин для Desktop | Тема для CLI |
|---|---|---|
| Что меняется | Интерфейс приложения, границы, акценты | Цветовая палитра терминала |
| Способ установки | Подсказка копирования / файл темы | Скрипт установки + `/theme` |
| Визуальная насыщенность | Высокая (поверхности, границы) | Низкая (только цвета) |
| Переносимость | Привязана к десктопной системе | Работает с любой цветовой палитрой терминала |
| Возможность отката | Однокликовое восстановление на большинстве систем | Повторный запуск `/theme` с другим названием |

## Какой выбрать для вашего потока работы?

**Выбирайте скины для Desktop, если:**
- Вы используете приложение Codex Desktop как основную рабочую среду.
- Хотите полную визуальную идентичность — тёмная низколюминесцентная, пастельная, неоновая, аниме.
- Вам нравится идея заранее созданных тем, которые можно восстановить за один клик.

**Выбирайте темы для CLI, если:**
- Вы работаете в основном в терминале.
- Хотите, чтобы ваш shell и Codex CLI использовали одну палитру.
- Предпочитаете темы как настраиваемый, переносимый конфиг.

## Можно ли использовать оба?

Да — они независимы. Многие люди используют тёмный скин для Desktop для приложения и соответствующую палитру CLI для терминала, чтобы вся рабочая среда выглядела как единая система. Поскольку темы CLI — это просто цветовые палитры, их сочетание легко: выберите палитру, которая существует в обоих мирах (Tokyo Night, Monokai Stone, Solarized) и примените её везде.
