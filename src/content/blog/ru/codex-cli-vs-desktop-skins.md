У Codex есть две принципиально разные системы оформления: **темы Codex CLI** и **оформления Codex Desktop**. Снаружи они выглядят похоже (обе меняют внешний вид вашей рабочей среды), но под капотом работают совершенно по-разному — и правильный выбор зависит от того, как именно вы используете Codex.

## Краткая версия

- **Оформления Codex Desktop** изменяют *интерфейс приложения* — боковую панель, границы, поверхности, акцентные цвета. Они насыщенные, визуально богатые и устанавливаются через диалоговое окно или файл темы.
- **Темы Codex CLI** изменяют *палитру цветов терминала* — фон, основной цвет текста и цвета синтаксиса. Они лёгкие, переносимые и устанавливаются командой, а применяются через `/theme`.

Если вы используете десктопное приложение — выбирайте оформления Codex Desktop. Если вы проводите большую часть времени в терминале — вам нужны темы Codex CLI.

## Что изменяет каждая система

| Аспект | Оформление Codex Desktop | Тема Codex CLI |
|---|---|---|
| Что изменяется | Интерфейс приложения, границы, акцентные цвета | Палитра цветов терминала |
| Способ установки | Диалоговое окно копирования / файл темы | Скрипт установки + команда `/theme` |
| Визуальная насыщенность | Высокая (поверхности, границы) | Низкая (только цвета) |
| Переносимость | Привязана к десктопному движку | Работает с любой терминальной палитрой |
| Возможность отмены | Восстановление одним щелчком в большинстве движков | Повторный запуск `/theme` с другим именем |

## Какой вариант подойдёт именно вам?

**Выберите оформления Codex Desktop, если вы:**
- Используете десктопное приложение Codex как основную рабочую среду.
- Хотите полноценную визуальную идентичность — тёмную при слабом освещении, пастельную, неоновую, аниме-стиля.
- Цените готовые темы, которые можно восстановить одним кликом.

**Выберите темы Codex CLI, если вы:**
- Работаете преимущественно в терминале.
- Хотите, чтобы оболочка (shell) и Codex CLI использовали одну и ту же цветовую палитру.
- Предпочитаете темы в виде конфигурационных файлов, поддерживаемых системой контроля версий и легко переносимых.

## Можно ли использовать обе системы одновременно?

Да — они независимы. Многие пользователи применяют тёмное оформление Codex Desktop для приложения и совместимую палитру Codex CLI для терминала, чтобы вся рабочая среда ощущалась как единая система. Поскольку темы Codex CLI — это просто цветовые палитры, их совмещение простое: выберите палитру, доступную в обеих системах (Tokyo Night, Monokai Stone, Solarized), и примените её повсюду.
