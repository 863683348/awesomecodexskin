ПОДБОРКА СКИН-ТЕМ — отличный старт, но это не единственный вариант — и для некоторых рабочих процессов он может не подойти. Если вам нужны точные темы приложений, встроенный галерея или чистая система тем для CLI, вот лучшие бесплатные и открытые альтернативы, представленные честно.

## Краткий список

| Двигатель | Лучше всего для | Способ установки | Платформы |
|---|---|---|---|
| [Codex Skin Manager](/blog/codex-skin-manager-guide/) | Визуальный просмотр + управление | Галерея UI, точное применение файлов | macOS, Windows |
| ReTheme | Подписанные, обновляемые темы сообщества | Библиотека тем, загружаемые файлы | macOS, Windows |
| Codex Themes CLI | Поклонники терминала | Команда CLI `/theme` | Кроссплатформенно |
| Codepilot | Любители TUI | Встроенная TUI `/skin` | Кроссплатформенно (npm) |
| Codex Themes (desktop) | Простая импортация на macOS | Импорт `.codextheme` | macOS |
| Стандартная тематика Codex | Без дополнительных установок | Встроенные настройки | Все |

## 1. Codex Skin Manager — ближайшая альтернатива 1:1

Если подход Dream Skin на основе запросов не подходит, **Codex Skin Manager** — естественный выбор. Это визуальный, галерейный двигатель: просматривайте, предварительно просматривайте, применяйте и откатывайте без написания запроса.

**Где он превосходит Dream Skin:**
- Точное применение — файлы тем применяются точно так, как указано, без вариаций интерпретации
- Визуальный предпросмотр до подтверждения
- Лучшее управление библиотекой для растущих коллекций

**Где он проигрывает:**
- Медленнее исследование — клик по предпросмотру лучше, чем вставка запросов
- Меньший каталог шаблонов, если вы не импортируете файлы

Для большинства людей сравнение двух вариантов сводится к *быстрому исследованию* против *точного применения*. Эта компромисс подробно рассмотрен в [Dream Skin vs Codex Skin Manager](/blog/codex-dream-skin-vs-skin-manager/).

## 2. ReTheme — подписанные темы сообщества

ReTheme — это движок на базе Tauri, который поставляется с **подписанными, обновляемыми темами сообщества** для Codex и ChatGPT. Если вас заботит целостность темы и автоматические обновления из проверенного каталога, это хороший выбор.

**Лучше всего для:** пользователей, которым нужен проверенный каталог с поддержкой обновлений, а не свободная раскладка шаблонов.

## 3. Codex Themes CLI — выбор минимальиста терминала

Для работы в CLI ничего не превосходит один файл конфигурации и команду `/theme`. Codex Themes CLI управляют темами CLI: проверять, просматривать, применять, откатывать и экспортировать совместимые палитры терминала.

**Лучше всего для:** рабочих процессов SSH/удаленных, пользователей dotfiles и всех, кто хочет изменить темы, которые можно скриптовать.

## 4. Codepilot — темизация через TUI

Codepilot (установка через npm) предоставляет встроенную TUI с командой `/skin`. Это хорошее промежуточное решение, если вы хотите интерфейс с меню, не покидая терминал.

**Лучше всего для:** людей, которым нравятся интерактивные меню, но не хотят использовать GUI-приложение.

## 5. Codex Themes (desktop) — простота только для macOS

Более легкий вариант для macOS, импортирующий файлы `.codextheme`. Простой, но ограничен платформой macOS.

## 6. Стандартная тематика Codex

Не забывайте, что Codex поставляется с встроенными настройками тематики. Перед добавлением любого двигателя проверьте, удовлетворяют ли встроенные параметры вашим потребностям — это нулевая установка и нулевой риск конфликта.

## Как выбрать

1. **Хотите самый большой каталог шаблонов и самую быструю эксплуатацию?** Оставайтесь с Dream Skin.
2. **Хотите точное применение + галерею для управления коллекцией?** Выберите [Codex Skin Manager](/blog/codex-skin-manager-guide/).
3. **Живете в терминале?** Идите в CLI (Codex Themes CLI или Codepilot).
4. **Хотите проверенный, управляемый обновлениями каталог?** Попробуйте ReTheme.

Вы также можете запускать два двигателя рядом (например, Dream Skin для исследования + менеджер для хранения) — просто оставьте один основным. Посмотрите [Сравнение двигателей тем Codex](/blog/codex-skin-engines-compared/) для полной картины многодвигательного использования, и [индекс тем](/skins/), чтобы увидеть, какой формат установки поддерживает каждая тема.
