Ваша цветовая палитра Codex CLI — это поверхность, на которую вы смотрите весь день, поэтому ей стоит уделить больше внимания, чем значению по умолчанию. В этом обзоре представлены лучшие темы терминала для Codex CLI в 2026 году — все они доступны в виде установленных синтаксических палитр — с оценкой по читаемости, утомлению глаз и совместимости с вашим терминалом.

## Как мы проводили ранжирование

Каждая тема оценивалась по четырём критериям:

1. **Контраст и читаемость** — различимость переднего плана и фона во время написания кода.  
2. **Утомление глаз** — снижение бликов при длительной работе.  
3. **Совместимость с терминалом** — наличие той же палитры в виде полноценной темы терминала.  
4. **Долговечность** — палитры, проверенные временем.

## 1. Tokyo Night — лучшая универсальная тема

Tokyo Night (тёмно-синяя палитра с низким уровнем бликов) занимает первое место. Её фон с лёгким синим оттенком снижает блики по сравнению с чисто чёрным, а синтаксические цвета тщательно разделены, обеспечивая хорошую читаемость как в 80-символьной строке приглашения, так и в длинных списках файлов. У неё есть хорошо известные аналоги для терминала и VS Code, что делает её проще всего синхронизировать во всей вашей рабочей среде.

## 2. Monokai Stone — лучшая тема для подсветки синтаксиса

Monokai Stone — классический выбор для работы, интенсивно использующей подсветку синтаксиса. Её тёплая, приглушённая фоновая палитра сохраняет яркость синтаксических цветов без излишнего контраста оригинального Monokai. Если вы проводите день за чтением diff-файлов и кода, эта палитра покажется вам наиболее «естественной» уже через несколько минут.

## 3. Solarized — лучшая тема для длительной работы

Solarized была разработана с учётом *lab-цветового пространства*, чтобы минимизировать утомление от контраста — и до сих пор остаётся эффективной. Приглушённая ретро-палитра комфортна для глаз даже при многократном использовании в течение нескольких часов, а соответствующая тема терминала доступна на всех платформах. Компромисс: меньшая «насыщенность», если вы предпочитаете яркие цвета.

## 4. Vivid Purple — лучшая тема для самовыражения

Если вы хотите, чтобы ваш CLI выглядел не как стандартный, а как *ваш собственный*, Vivid Purple добавляет насыщенный фиолетовый акцент, сохраняя при этом достаточный контраст переднего плана для комфортного чтения. Отличный второй вариант темы, чтобы освежить рабочее окружение.

## 5. Amber Nocturne — лучший тёплый тёмный вариант

Amber Nocturne — выбор для любителей тёплых тёмных тем: мягкая палитра с янтарным оттенком на тёмном фоне оказывает меньшее воздействие на глаза по сравнению с прохладными синими темами в полумраке. Идеально сочетается с янтарной темой терминала, создавая целостное ретро-футуристическое рабочее пространство.

## Как установить любую из этих тем

Каждая из перечисленных выше тем устанавливается как синтаксическая палитра Codex CLI одной командой, а затем применяется через `/theme`:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
/theme
```

## Какую тему выбрать?

- **Рекомендация по умолчанию:** Tokyo Night — оптимальный баланс читаемости и совместимости.  
- **Интенсивная работа с синтаксисом:** Monokai Stone.  
- **Работа в течение всего дня или повышенная чувствительность глаз:** Solarized.  
- **Самовыражение:** Vivid Purple или Amber Nocturne.
