Палитра вашего Codex CLI — это поверхность, на которую вы смотрите весь день, поэтому она заслуживает больше внимания, чем стандартная. Этот обзор представляет лучшие темы терминала для Codex CLI в 2026 году — все доступны как установленные синтаксические палитры — по читаемости, усталости глаз и тому, насколько хорошо они сочетаются с вашим терминалом.

## Как мы ранжировали

Каждая тема оценивалась по четырём критериям:

1. **Контраст и читаемость** — разделение фонового и фонового цвета при программировании.
2. **Усталость глаз** — снижение бликов для длительных сессий.
3. **Совместимость с терминалом** — наличие той же палитры в качестве реальной темы терминала.
4. **Долговечность** — палитры, выдержавшие испытание временем.

## 1. Tokyo Night — лучший универсальный выбор

Tokyo Night (темно-синяя палитра с низким уровнем бликов) лидирует в списке. Ее синеватый темный фон снижает блики по сравнению с черным, а цвета синтаксиса тщательно разделены, поэтому она остается читабельной как в 80-столбцовом запросе, так и в длинных списках файлов. У нее есть известная тема терминала и VS Code, что делает ее наиболее простой для синхронизации по всей вашей системе.

## 2. Monokai Stone — лучший выбор для подсветки синтаксиса

Monokai Stone — классический выбор для работы с интенсивным синтаксисом. Ее теплый, приглушенный фон сохраняет читаемость ярких цветов синтаксиса без резкого контраста оригинального Monokai. Если вы проводите день, читая диффы и код, это будет самая "правильная" палитра после нескольких минут использования.

## 3. Solarized — лучший выбор для длительных сессий

Solarized был разработан вокруг *пространства цвета lab*, чтобы минимизировать усталость от контраста — и он до сих пор работает. Приглушенная ретро-палитра легко воспринимается глазами часами, и она существует как тема терминала на каждой платформе. Недостаток: меньше "выделения", если вам нравятся яркие цвета.

## 4. Vivid Purple — лучший выбор для индивидуальности

Если вы хотите, чтобы ваш CLI чувствовался менее похожим на стандартный и более как *ваш*, Vivid Purple придает насыщенный фиолетовый образ, сохраняя достаточно высокий контраст переднего плана для удобного чтения. Это отличный второй вариант для смены настроения.

## 5. Amber Nocturne — лучший выбор для теплых темных оттенков

Amber Nocturne — выбор для теплых темных оттенков — мягкая палитра янтаря на темном фоне, которая мягче для глаз, чем холодные синие темы в затемненных комнатах. Она прекрасно сочетается с терминальной темой янтаря для создания согласованной, ретро-футуристической рабочей среды.

## Как установить любую из этих тем

Каждая тема выше устанавливается как синтаксическая палитра Codex CLI одной командой, а затем применяется через `/theme`:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
/theme
```

## Какой выбрать?

- **Рекомендация по умолчанию:** Tokyo Night — лучшее соотношение читаемости и совместимости.
- **Работа с интенсивным синтаксисом:** Monokai Stone.
- **Долгосрочные сессии или чувствительные глаза:** Solarized.
- **Индивидуальность:** Vivid Purple или Amber Nocturne.
