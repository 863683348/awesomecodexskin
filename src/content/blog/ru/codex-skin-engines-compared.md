Существует пять основных способов установки скинов в Codex, и все они работают принципиально по-разному. Выберите неподходящий — и вы будете бороться с ним неделями. Выберите правильный — и смена внешнего вида займёт десять секунд. В этом сравнении все пять вариантов представлены рядом, чтобы вы могли принять решение за один просмотр.

## Пять движков вкратце

| Движок | Поддерживаемые платформы | Способ установки | Для кого лучше всего подходит |
|---|---|---|---|
| Codex Dream Skin | macOS, Windows | Через агент / готовые пресеты | Для тех, кто хочет полного отсутствия настроек |
| Codex Skin Manager | macOS, Windows | Встроенное графическое управление | Для тех, кто предпочитает визуальный выбор |
| ReTheme | macOS, Windows | Подписанные темы сообщества | Для тех, кто ценит тщательно отобранные и проверенные темы |
| Codex Themes CLI | Кроссплатформенный | Команда CLI `/theme` | Для пользователей терминала |
| Codepilot | Кроссплатформенный (через npm) | Встроенный TUI-интерфейс `/skin` | Для продвинутых пользователей, живущих в терминале |

## Codex Dream Skin — вариант «просто вставьте»  

Dream Skin (проект Fei-Away, автор нескольких скинов из этого индекса) устанавливает скины по естественно-языковому запросу. Вы копируете строку вроде «применить светлую тему Clear Glass», вставляете её — и движок применяет цветовую палитру. Никаких файлов для управления, никаких команд для запоминания.

**Преимущества:** самый быстрый путь к новому внешнему виду; пресеты сохраняются, поэтому восстановить стандартные настройки можно одним кликом.  
**Недостатки:** менее точен по сравнению с файловыми темами — вы описываете желаемый вид, а не загружаете строго определённую спецификацию.

## Codex Skin Manager — визуальный выбор  

Десктопный менеджер со встроенной галереей: просмотр, предварительный просмотр, применение, откат. Это ближе всего к «магазину приложений для скинов». Если вам нравится просматривать превью перед тем, как окончательно выбрать тему, этот движок — ваш выбор.

**Преимущества:** визуальный предпросмотр до применения; удобен для нетехнических пользователей.  
**Недостатки:** работает только со своей собственной галереей; импорт сторонних файлов менее удобен, чем с помощью CLI-инструментов.

## ReTheme — вариант с тщательной подборкой  

ReTheme распространяет подписанные темы сообщества, то есть каждая тема проходит ручную проверку перед тем, как попасть к вам. Это снижает риск получения повреждённого или вредоносного файла, но в обмен на более скромный каталог.

**Преимущества:** безопасность и тщательная подборка; подписанные темы устанавливаются без ошибок.  
**Недостатки:** выбор тем меньше, чем в открытых экосистемах.

## Codex Themes CLI — классический терминальный подход  

Подход через CLI (например, ychampion/codex-themes, который портирует такие темы, как Tokyo Night и Monokai Stone) рассматривает скины как пакет, который устанавливается и переключается командой: `/theme monokai-stone`. Он быстр, поддерживает автоматизацию и хорошо интегрируется с dotfiles.

**Преимущества:** поддержка скриптов; контроль версий; тот же рабочий процесс, что и у других CLI-инструментов.  
**Недостатки:** встроенный предпросмотр отсутствует; более высокий порог входа для пользователей, не работающих в терминале.

## Codepilot — мощный TUI-инструмент  

Codepilot (устанавливается через npm) предоставляет полноценный TUI-менеджер скинов с командами `/skin`, проверкой корректности, предпросмотром, откатом изменений и возможностью экспорта цветовой палитры терминала. Это наиболее функциональный из терминальных вариантов.

**Преимущества:** проверка, предпросмотр, откат и экспорт палитры — всё в одном инструменте; кроссплатформенность.  
**Недостатки:** больше компонентов по сравнению с базовым CLI; избыточен, если вам нужна всего одна тема.

## Какой движок выбрать?

- **Хотите красивый внешний вид быстро:** Dream Skin.  
- **Предпочитаете выбирать темы по превью:** Codex Skin Manager.  
- **Важны проверенные и подписанные темы:** ReTheme.  
- **Работаете в терминале и хотите поддержку скриптов:** Codex Themes CLI.  
- **Нужен максимально функциональный инструмент:** Codepilot.

Все пять движков совместимы со всеми скинами из этого индекса — большинство из них распространяются либо как текстовые пресеты, либо как файлы тем, которые любой из этих движков может обработать. Начните с понравившегося скина, например [Clear Glass](/skins/clear-glass/) или [Gothic Void Expedition](/skins/gothic-void-expedition/), и выберите движок, соответствующий вашему стилю работы.

## Краткий FAQ

**Можно ли одновременно использовать два движка?**  
Да, но один из них должен быть активным менеджером. Если два движка одновременно записывают пресеты, они могут перезаписывать друг друга. Выберите один основной, а остальные используйте только для импорта.

**Работают ли движки со всеми скинами?**  
Не всегда. Движки, основанные на промптах, требуют текстового описания; файловые движки требуют соответствующего формата файла. Поле «Формат установки» на странице каждого скина указывает, для какого движка он предназначен.

**У какого движка самая большая библиотека тем?**  
Наиболее обширные каталоги — в открытых экосистемах: пресеты Dream Skin и порты CLI, поскольку их могут дополнять любые участники сообщества. В курируемых менеджерах библиотеки меньше, но темы в них безопаснее.
