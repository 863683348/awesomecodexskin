Изменение темы в Codex CLI отличается от процесса в Codex Desktop. Вместо визуального интерфейса тема Codex CLI заменяет **палитру цветов терминала** — фон, основной текст и цвета синтаксиса — чтобы приглашение командной строки, автодополнения и вывод оставались читаемыми в оболочке.

Ниже приведён полный рабочий процесс: от однокомандного переключателя `/theme` до установки совершенно новых палитр.

## Самый быстрый способ: `/theme`

В Codex CLI встроена команда для управления темами. Откройте приглашение командной строки и введите:

```bash
/theme
```

Это выведет список всех установленных в данный момент тем. Используйте клавиши со стрелками (или введите имя темы) для мгновенного применения — перезапуск не требуется. Если вы установили синтаксическую тему, например Tokyo Night, она появится в этом списке под своим точным именем:

```bash
/theme Tokyo Night
```

## Сначала установите новую палитру

Команда `/theme` показывает только те темы, которые уже установлены. Синтаксические палитры (Tokyo Night, Monokai Stone, Solarized) устанавливаются с помощью скрипта, который переносит палитру в каталог тем Codex CLI:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
# затем выведите список и примените нужную тему:
/theme
```

Репозиторий Bearded Theme Ports содержит более 50 вариантов — Solarized, Tokyo Night, Monokai Stone и другие — так что вы можете протестировать несколько палитр за считанные секунды.

## Использование менеджера тем для отката и синхронизации с терминалом

Если вы часто меняете темы, CLI-менеджер избавит вас от догадок:

- **Codex Themes CLI** (`ychampion/codex-themes`) — CLI на языке Go, позволяющий **проверять, предварительно просматривать, применять, откатываться и экспортировать** соответствующую палитру в профиль вашего терминала. Примените тему командой `codex-theme apply <name>`; вернуться к предыдущей — одной командой.
- **Codepilot** (`charzhu/codepilot`) — дистрибутив Codex CLI со встроенным TUI:

```bash
npm i -g @charzhu/codepilot
# выполните /skin внутри TUI, чтобы выбрать одну из 16 встроенных тем
```

## Согласование терминала и редактора

Палитра выглядит лучше всего, когда терминал, CLI и редактор используют одну и ту же тему. С помощью Codex Themes CLI вы можете экспортировать одни и те же цвета в профиль терминала, так что оболочка и Codex CLI будут совпадать сразу после одного применения. Дополните это портированной темой для редактора (например, Tokyo Night для VS Code), чтобы получить единое рабочее окружение.

## Устранение неполадок

- **Тема не отображается в `/theme`** — сначала запустите скрипт установки, затем перезапустите приглашение командной строки.
- **Цвета выглядят некорректно после смены темы** — перезапустите Codex CLI; некоторые порты кэшируют цвета при запуске.
- **Хотите использовать ту же палитру в оболочке** — воспользуйтесь функцией экспорта Codex Themes CLI, чтобы записать палитру в профиль вашего терминала.
