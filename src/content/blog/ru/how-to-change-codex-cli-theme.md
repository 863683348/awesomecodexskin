ИЗМЕНЕНИЕ ТЕМЫ В CODEx CLI ПРОИСХОДИТ ПО ДРУГОМУ ПРОЦЕССУ, ЧЕМ В CODEx DESKTOP. ВМЕСТО ВИЗУАЛЬНОЙ ХРОМЫ, ТЕМА CODEx CLI МЕНЯЕТ **ПАЛЕТУ ЦВЕТОВ ТЕРМИНАЛА** — ФОН, ПЕРЕДНИЙ ПЛАН И ЦВЕТА СИНТАКСИСА — ЧТОБЫ ВАШ ПРОМОТ, АВТОДОПОЛНЕНИЯ И ВЫВОД ОСТАЛИСЬ ЧИТАЕМЫМИ В ОКОНЧЕНИИ.

Вот полный рабочий процесс, от однострочной команды `/theme` до установки новых палитр.

## Самый быстрый способ: /theme

CODEx CLI поставляется с встроенной командой темы. Откройте командную строку и введите:

```bash
/theme
```

Это выводит все темы, которые сейчас установлены. Нажмите клавиши со стрелками (или введите имя), чтобы применить одну из них мгновенно — перезапуск не требуется. Если вы установили тему синтаксиса, например, Tokyo Night, она появляется в этом списке под своим точным названием:

```bash
/theme Tokyo Night
```

## Установите новую палитру сначала

`/theme` показывает только те темы, которые вы установили. Палитры синтаксиса (Tokyo Night, Monokai Stone, Solarized) устанавливаются из скрипта, который переносит палитру в каталог тем Codex CLI:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
# затем список и применение:
/theme
```

Репозиторий Bearded Theme Ports содержит более 50 вариантов — Solarized, Tokyo Night, Monokai Stone и другие — поэтому вы можете протестировать несколько палитр за секунды.

## Используйте менеджер тем для отката и синхронизации терминала

Если вы часто меняете темы, CLI-менеджер убирает неопределенность:

- **Codex Themes CLI** (`ychampion/codex-themes`) — Go CLI, который может **валидировать, просматривать, применять, откатывать и экспортировать** соответствующую палитру в ваш профиль терминала. Примените с помощью `codex-theme apply <name>`; вернитесь к предыдущей теме одной командой.
- **Codepilot** (`charzhu/codepilot`) — распределение Codex CLI с встроенным TUI:

```bash
npm i -g @charzhu/codepilot
# запустите /skin внутри TUI, чтобы выбрать одну из 16 встроенных тем
```

## Согласуйте терминал и редактор

Палитра выглядит лучше, когда терминал, CLI и редактор используют одну и ту же. С помощью Codex Themes CLI вы экспортируете те же цвета в ваш профиль терминала, так что оболочка и Codex CLI совпадают после одного применения. Сопоставьте его с портированной темой редактора (например, Tokyo Night в VS Code) для согласованной рабочей среды.

## Решение проблем

- **Тема не появляется в `/theme`** — сначала запустите скрипт установки, затем снова откройте командную строку.
- **Цвета выглядят неправильно после переключения** — перезапустите Codex CLI; некоторые порты кэшируют цвета при запуске.
- **Хотите ту же палитру в терминале** — используйте экспорт Codex Themes CLI, чтобы записать палитру в ваш профиль терминала.
