Темы Codex CLI изменяют **цветовую палитру терминала** — фон, текст и цвета синтаксиса — чтобы ваш запрос и вывод оставались читаемыми в терминале. Вы применяете их с помощью встроенной команды `/theme`: выполните `/theme`, чтобы увидеть установленные темы, выберите одну, и она будет применена мгновенно. В отличие от Codex Desktop, CLI не имеет визуальной оболочки; тема — это только цвета, которые вы видите.

## Быстрый старт

1. Установите порт темы (одноразово): `curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh`
2. Откройте Codex CLI и выполните `/theme`.
3. Выберите тему (например, `/theme Tokyo Night`) — она применяется немедленно.

## Команда /theme

Самый быстрый способ использовать тему CLI — это встроенная команда `/theme`:

```bash
# в Codex CLI:
/theme
```

Это выводит список установленных тем. Выберите одну, чтобы применить ее мгновенно.

## Установка темы синтаксиса

Темы синтаксиса (например, Monokai Stone, Tokyo Night, Solarized) устанавливаются через скрипт, который переносит палитру в каталог тем Codex CLI:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
# затем:
/theme Tokyo Night
```

Репозиторий Bearded Theme Ports содержит более 50 вариантов тем Bearded — Solarized, Tokyo Night, Monokai Stone и другие.

## Управление темами с помощью CLI-инструментов

Два инструмента делают управление темами CLI безболезненным:

- **Codex Themes CLI** (`ychampion/codex-themes`) — CLI на Go: проверяет, предварительно просматривает, применяет, откатывает и экспортирует совместимые цветовые палитры терминала. Идеально, если вы хотите, чтобы ваш терминал и Codex CLI использовали одинаковую палитру.
- **Codepilot** (`charzhu/codepilot`) — распределение Codex CLI с встроенным TUI-персонализацией:

```bash
npm i -g @charzhu/codepilot
# затем запустите /skin внутри TUI, чтобы выбрать встроенную тему
```

Codepilot поставляется с 16 встроенными TUI-темами (цвета фона + поверхности).

## Решение проблем

- **`/theme` сообщает, что темы не установлены** — сначала запустите скрипт установки, затем снова откройте подсказку.
- **Цветовая палитра выглядит неправильно** — перезапустите Codex CLI после применения; некоторые порты кэшируют цвета при запуске.
- **Хотите, чтобы терминал соответствовал** — используйте экспорт из Codex Themes CLI, чтобы записать ту же палитру в ваш профиль терминала.
