Скины Codex позволяют изменить внешний вид OpenAI Codex Desktop и Codex CLI, чтобы рабочая область соответствовала вашему вкусу — темная палитра с низкой яркостью для ночного режима, пастельная поверхность для дневного времени или неоновый стиль просто для развлечения.

Это руководство охватывает все способы установки скина Codex, от одного запроса установки до менеджеров тем для CLI.

## Краткий вариант

Большинство скинов на этом индексе устанавливаются одинаково:

1. Выберите скин и откройте его страницу деталей.
2. Скопируйте запрос на установку (или загрузите файл темы, для скинов в формате .codedrobe-theme).
3. Вставьте запрос в Codex Desktop или выполните команду в Codex CLI.
4. Двигатель тем применяет палитру сразу — перезагрузка не требуется на большинстве движков.

Вот и всё. Скины — это настройки, а не код, поэтому переключение происходит быстро и обратимо.

## Метод 1: Копирование и вставка запроса на установку (самый быстрый)

Большинство скинов Codex — особенно предустановленные темы из [Codex Dream Skin](https://github.com/Fei-Away/Codex-Dream-Skin), открытого исходного кода для вставки — устанавливаются из одного естественного запроса.

На странице деталей любого скина, в разделе **Запрос на установку** находится готовый к вставке запрос, например:

```text
Codex, примените светлую тему 'Прозрачное стекло' — чистая поверхность с низким уровнем отвлекающих факторов для моей рабочей области.
```

Скопируйте его, откройте Codex и вставьте. Двигатель считывает запрос и применяет палитру, границы и акцентные цвета, определенные в теме.

> **Совет:** если запрос применяет предустановку, двигатель сохраняет её, так что вы можете вернуться к стандартной теме одним щелчком.

## Метод 2: Загрузка файла темы (.codedrobe-theme)

Некоторые скины поставляются в виде загружаемого файла .codedrobe-theme. Для этих:

1. Нажмите **Загрузить .codedrobe-theme** на странице скина.
2. Сохраните файл в удобное место.
3. Откройте его в Codex Desktop — поддерживаемые движки автоматически импортируют тему.

Этот метод часто используется на галереях, таких как codexskins.org, которые хранят готовые файлы тем.

## Метод 3: Установка темы CLI с помощью команды

Темы CLI Codex устанавливаются по другому пути. Скины с форматом установки `tmtheme` (например, Bearded Theme Ports) устанавливаются одной командой:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
# затем в Codex CLI выполните:
/theme Tokyo Night
```

Инструменты, такие как [Codex Themes CLI](https://github.com/ychampion/codex-themes) и [Codepilot](https://github.com/charzhu/codepilot), управляют темами CLI для вас — проверяют, предварительно просматривают, применяют, откатывают и экспортируют совместимые палитры терминала.

## Какие движки поддерживают скины?

| Движок | Платформы | Способ установки |
|---|---|---|
| Codex Dream Skin | macOS, Windows | Запрос / предустановка |
| Codex Skin Manager | macOS, Windows | Встроенный менеджер |
| Codex Themes (десктоп) | macOS | Импорт .codextheme |
| ReTheme | macOS, Windows | Подписанные темы сообщества |
| Codex Themes CLI | Кроссплатформенный | CLI `/theme` |
| Codepilot | Кроссплатформенный (npm) | Встроенный TUI `/skin` |

## Как переключиться или вернуться к предыдущей теме

- **Движки с предустановками (Dream Skin и т.д.):** движок сохраняет стандартную предустановку — обычно кнопка "Вернуть стандартный вид" восстанавливает ваш оригинальный внешний вид.
- **CLI:** `/theme` показывает установленные темы; повторно запустите команду с другим именем, чтобы переключиться.
- **Файлы тем:** повторно импортируйте предыдущий .codedrobe-theme или запустите стандартную тему движка.
