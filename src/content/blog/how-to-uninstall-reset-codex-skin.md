# How to Uninstall or Reset a Codex Skin

You've been experimenting with Codex skins — trying different themes, customizing colors, testing new engines. Now you want to go back to default, or remove a skin that's causing problems. Here's how to uninstall or reset your Codex skin safely.

## Method 1: Reset to Default (Quickest)

If you just want to return to the original theme without deleting anything:

1. Open Codex Skin Studio
2. Click the "Reset" or "Restore Default" button (usually in the top-right corner)
3. Confirm the reset when prompted
4. Your Codex instance will reload with the default theme

This method keeps all your saved presets intact — you're just switching back to the factory settings.

## Method 2: Delete a Specific Skin

To remove a skin you no longer want:

1. Open Codex Skin Studio
2. Navigate to the "My Themes" or "Installed Skins" section
3. Find the skin you want to remove
4. Click the delete/trash icon next to it
5. Confirm deletion

The skin file is removed from your system. Any Codex windows using that skin will revert to the previous theme or default.

## Troubleshooting Common Issues

### Skin not applying after reinstall
- Clear Codex's cache: `Settings > Appearance > Clear Cache`
- Restart Codex completely
- Reapply the skin from Skin Studio

### Multiple skins conflicting
- Only enable one skin at a time
- Check for override conflicts in Skin Studio settings
- Use the "Apply to All Windows" option carefully

### Reset didn't work
- Try restarting Codex first
- Check if another skin is overriding your changes
- Reinstall Codex Skin Studio if problems persist

## Best Practices

- **Backup before deleting**: Export your important presets
- **One at a time**: Change one skin at a time to isolate issues
- **Use presets**: Save your favorite configurations as presets
- **Keep default**: Never delete the default theme — it's your safety net

## FAQ

**Q: Can I recover a deleted skin?**
A: If you exported it as a preset, yes. Otherwise, you'll need to re-download or recreate it.

**Q: Will resetting delete my custom settings?**
A: No, preset saves are kept. Only the active theme changes.

**Q: How do I switch between multiple skins?**
A: Use Codex Skin Studio's theme switcher or the skin selector in Codex's settings.

# 如何卸载或重置 Codex 皮肤

你一直在尝试 Codex 皮肤——尝试不同的主题、自定义颜色、测试新的引擎。现在你想回到默认设置，或移除导致问题的皮肤。以下是安全卸载或重置 Codex 皮肤的方法。

## 方法 1：重置为默认（最快）

如果你只是想回到原始主题而不删除任何内容：

1. 打开 Codex Skin Studio
2. 点击"重置"或"恢复默认"按钮（通常在右上角）
3. 在提示时确认重置
4. 你的 Codex 实例将重新加载默认主题

此方法保留所有已保存的预设——你只是切换回出厂设置。

## 方法 2：删除特定皮肤

要移除你不再需要的皮肤：

1. 打开 Codex Skin Studio
2. 导航到"我的主题"或"已安装皮肤"部分
3. 找到要移除的皮肤
4. 点击旁边的删除/垃圾桶图标
5. 确认删除

皮肤文件从你的系统中移除。任何使用该皮肤的 Codex 窗口将恢复为之前的主题或默认。

## 常见问题排除

### 重新安装后皮肤未应用
- 清除 Codex 缓存：`设置 > 外观 > 清除缓存`
- 完全重启 Codex
- 从 Skin Studio 重新应用皮肤

### 多个皮肤冲突
- 一次只启用一个皮肤
- 检查 Skin Studio 设置中的覆盖冲突
- 谨慎使用"应用到所有窗口"选项

### 重置无效
- 先尝试重启 Codex
- 检查是否有其他皮肤覆盖你的更改
- 如果问题持续，重新安装 Codex Skin Studio

## 最佳实践

- **删除前备份**：导出重要的预设
- **一次一个**：一次更改一个皮肤以隔离问题
- **使用预设**：将喜欢的配置保存为预设
- **保留默认**：永远不要删除默认主题——它是你的安全网

## 常见问题

**Q: 我能恢复已删除的皮肤吗？**
A: 如果你将其导出为预设，可以。否则，你需要重新下载或重新创建。

**Q: 重置会删除我的自定义设置吗？**
A: 不会，预设保存保持不变。只有活动主题更改。

**Q: 我如何在多个皮肤之间切换？**
A: 使用 Codex Skin Studio 的主题切换器或 Codex 设置中的皮肤选择器。
