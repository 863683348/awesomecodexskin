The mono-terminal category is the closest thing Codex has to "no decoration." These are skins that treat the editor like a terminal: one background, a handful of syntax colors, and nothing else competing for attention. For people who live in the command line, this is not minimalism for its own sake — it is a functional choice. The fewer colors on screen, the faster your eye lands on what matters.

There are five skins in this category. They share a philosophy: syntax colors should be the loudest thing in the window, and everything else should be quiet.

## Monokai Stone: the classic, desaturated

Monokai Stone is the terminal-native take on the Monokai formula. The signature Monokai palette is high-contrast and loud; Stone pulls the saturation down while keeping the dark background and the recognizable highlight colors.

What you get is a theme that still reads "Monokai" at a glance — the pink string literals, the green comments, the yellow keywords — but without the harshness that makes the original feel like it is shouting at you. It is the same muscle memory, softer edges.

If you already know Monokai, this is the gentlest upgrade path in the category. If you have never tried it, this is the version that gives you the idea without the eye strain.

## Solarized CLI: the research-backed palette

Solarized is famous for being designed on color science instead of taste. Ethan Schoonover chose 16 colors with precise relative luminance, which is why the theme stays readable across drastically different environments — bright office, dim room, cheap monitor, premium panel.

The CLI variant keeps that engineering pedigree and applies it to the Codex interface. The background is the soft blue-gray that Solarized is known for, and the accent colors stay in the same luminance band, so nothing jumps out of place.

The trade-off is real: Solarized can look muted next to neon-heavy themes. That is the point. You are trading spectacle for consistency, and for long workdays it is a good trade.

## Tokyo Night (ychampion): neon, but disciplined

Tokyo Night started as a VS Code theme and became a whole family. The ychampion variant in the Codex library is the terminal-flavored member of that family.

Where Solarized is muted and Monokai Stone is warm, Tokyo Night goes for a cool, slightly electric mood: deep blue background, bright cyan and pink accents, purple highlights. It is the most colorful skin in the mono-terminal category, but the discipline is in the placement — the neon stays on syntax colors and never spills into the chrome.

If you want the focus benefits of a minimal skin but you find pure desaturation boring, Tokyo Night (ychampion) is the compromise that still feels like a modern editor.

## Monokai Stone (CLI): the same palette, terminal-native

The CLI-labeled version of Monokai Stone exists because the same palette can render differently depending on how the skin is loaded. The CLI build is tuned for the terminal-embedded Codex experience, where the palette interacts with your actual shell colors.

Between Monokai Stone and Monokai Stone (CLI), pick based on how you run Codex. If you use the desktop app with the editor skin, the main build is the right one. If you spend time in the terminal-facing UI, the CLI build keeps the palette consistent with your shell environment.

## Codepilot built-in TUI skins: the default that is actually good

The built-in TUI skins that ship with Codepilot are easy to dismiss because they come free with the tool. That is a mistake. They are the reference implementation of what a mono-terminal skin should be: minimal chrome, clear syntax hierarchy, and zero surprises.

They also set the baseline for the whole category. When you are comparing the other four skins, the built-in TUI look is the neutral point — "at least as clean as the default" is a fair standard for any mono-terminal skin to meet.

## How to pick among the five

- **Monokai Stone** if you know Monokai and want it softer
- **Solarized CLI** if you want a research-backed palette for long days
- **Tokyo Night (ychampion)** if you want minimal structure with modern color
- **Monokai Stone (CLI)** if you run Codex through the terminal
- **Codepilot built-in TUI skins** if you want the default that just works

All five are installable through the Codex theme manager. The [terminal sync guide](/blog/codex-skin-terminal-sync/) covers how to keep your shell and editor palettes aligned, which matters more in this category than any other — a mono-terminal skin only feels right when the terminal around it agrees.
