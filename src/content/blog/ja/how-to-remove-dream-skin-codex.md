Codex ドリームスキンを変更したくない、または別のエンジンに切り替えたいですか？ Codex ドリームスキンを削除するのは簡単ですが、*きれいに*削除することが重要です。半分だけアンインストールすると、アクティブなテーマが適用されたままになり、次のエンジンと静かに競合する可能性があります。ここでは、macOS および Windows で適切に削除する方法を紹介します。

## 始める前に: アクティブなテーマを最初にリセットしてください

ドリームスキンは現在、Codex のテーマの**アクティブな適用者**になっている可能性があります。アプリをアクティブな状態でアンインストールすると、カスタムテーマが残り、管理できなくなることがあります。

1. ドリームスキンを開きます。
2. **デフォルトに戻す**を使用して、Codex を元の見た目に戻します。
3. 続ける前に、Codex でデフォルトテーマが表示されていることを確認してください。

他のエンジン（[Codex スキンマネージャー](/blog/codex-skin-manager-guide/)など）に移行する場合は、まずそれをインストールし、新しいアクティブな適用者として設定した後、ドリームスキンをアンインストールしてください。これにより、どのエンジンもテーマを変更できない空白期間を避けることができます。

## macOS での削除

1. ドリームスキンと Codex Desktop を終了してください。
2. Applications からドリームスキンアプリをゴミ箱にドラッグします。
3. 残った構成フォルダーをクリアします（存在する場合）: `~/Library/Application Support/Codex-Dream-Skin/`（またはインストール時の正確なフォルダ名）。
4. ゴミ箱を空にします。

## Windows での削除

1. ドリームスキンと Codex Desktop を閉じます。
2. **設定 → アプリ → インストール済みアプリ**（またはコントロールパネルの「プログラムの追加または削除」）からアンインストールします。
3. 残っているデータフォルダーを削除します: `%APPDATA%\Codex-Dream-Skin`（またはインストール時に保存された場所）。
4. ソースからインストールした場合やパッケージマネージャー経由でインストールした場合は、対応するアンインストールコマンドを実行してください。

## すべてのファイルが削除されているか確認してください

アンインストール後、次を確認してください:

- Codex が**デフォルトテーマ**を表示していること（最初にアクティブなテーマをリセットした場合、これは正しいはずです）。
- ドリームスキンのプロセスが実行されていないこと（アクティビティモニターやタスクマネージャーで確認してください）。
- 他のエンジンが今後テーマを適用しようとしていないこと — 他のエンジンをインストールした場合は、それがアクティブなものの確認してください。

## エンジンを切り替える場合？

多くの人がドリームスキンをアンインストールして別のものに切り替えています。一般的な2つの道のりは次の通りです:

- **ギャラリーUIへ:** [Codex スキンマネージャーガイド](/blog/codex-skin-manager-guide/)
- **CLIテーマ化へ:** [エンジン比較](/blog/codex-skin-engines-compared/)には、Codex Themes CLI および Codepilot などのCLIオプションが含まれています

また、別の*エンジン*ではなく、別の*スキン*を望んでいる場合は、[スキンインデックス](/skins/)を参照してください — スキンを切り替えるのは、エンジンを切り替えるよりも常に速いです。

## まとめFAQ

**ドリームスキンをアンインストールすると、適用中のスキンは削除されますか？**
最初にデフォルトに戻した場合、いいえ — Codex は組み込みテーマに戻ります。ドリームスキンによって保存されたカスタムプレセットはアプリとともに削除されます。

**後で再インストールできますか？**
はい、ドリームスキンは無料でオープンソースです。公式リポジトリから再インストールし、スキンページのプロンプトは引き続き動作します。

**ドリームスキンを削除すると、他のエンジンに影響しますか？**
いいえ、ただし、最後に勝つ競合を防ぐために、一度に1つのアクティブな適用者だけをインストールしてください。
