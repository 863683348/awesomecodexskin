Tokyo Night は、単一のツールから広範なエコシステムへと拡大した、稀有なテーマです。当初は人気のターミナルテーマとして登場し、次に VS Code の定番テーマとなり、現在では本 Codex スキンインデックス内にも複数の移植版が存在します。一つのカラーパレットがさまざまなツール間で移行・展開していく様子を観察することは、スキンの移植性（portability）がなぜ重要であるかを理解するための最良の事例研究です。

## Tokyo Night のファミリーツリー

このパレット——ナイトブルー系の背景色、柔らかなラベンダーとシアンのアクセント、高い可読性——は、美しさと実用性の両方を兼ね備えているため、急速に普及しました：

- **最初はターミナル向け。** Tokyo Night の発祥地であり、暗めのブルーグレー系背景はターミナル上で非常に読みやすい設計です。
- **次にエディター向け。** VS Code での採用により、開発者コミュニティにおいて「一家に一台」的な存在となりました。
- **そして Codex 向け。** 本インデックスには、いくつかの形で移植版が登場しています：[Tokyo Night (CLI)](/skins/tokyo-night-cli/)、[Tokyo Night (ychampion)](/skins/tokyo-night-ychampion/)、および Bearded シリーズからの移植版である [Bearded Tokyo Night](/skins/bearded-tokyo-night/)。

同じトーンの系統でありながら、実装はやや異なります——それがまさにテーマエコシステムの本質です。

## この移行が Codex スキンにもたらす教訓

**1. 移植性は機能である。** Tokyo Night が Codex 上で3種類の形で存在するのは、「どこでも使いたい」というユーザーの強い要望があったからです。スキンを選択する際は、過去に多数の移植実績を持つパレットを優先しましょう。[Monokai Stone](/skins/monokai-stone-cli/) や [Solarized](/skins/solarized-cli/) も同様の経緯を持ち、次に採用するツールへも容易に移植可能です。

**2. 移植版は細部で異なる。** [Tokyo Night (CLI)](/skins/tokyo-night-cli/) と [Tokyo Night (ychampion)](/skins/tokyo-night-ychampion/) は、バイト単位で同一ではありません。それぞれ異なる作者が、コントラストやアクセント色の処理を独自に調整しています。同じファミリーでありながら、わずかに異なる雰囲気を醸し出します。これは当然のことであり、自分の好みに最も合うバリエーションを選べばよいのです。

**3. CLI バリエーションが最も耐久性が高い。** ターミナル由来のテーマは、tmtheme／CLI 形式で提供されるため、最も幅広いツール群へのインポートが可能です。なぜ構造化されたフォーマットが、文書ベースのプリセットよりも長く生き残るのかについては、[フォーマットガイド](/blog/codex-skin-format-ecosystem/) をご参照ください。

## ツール横断型 Tokyo Night 環境の構築

全ファミリーの統一感を実現したいですか？以下は実際に動作する設定例です：

1. **Codex：** [Tokyo Night (CLI)](/skins/tokyo-night-cli/)（あるいは好みに合う場合は ychampion バリエーション）をインストールします。
2. **ターミナル：** 同じパレットは iTerm2、Windows Terminal、kitty など、多数のエミュレーターに対応しています。お使いのエミュレーター向けに、オリジナルの Tokyo Night テーマをダウンロードしてください。
3. **VS Code：** オリジナルの Tokyo Night テーマは、わずか2秒でインストールできます。
4. **シェルの構文ハイライト：** シェルが構文ハイライト機能をサポートしている場合、このパレットの ANSI カラーはそのまま適用可能です。

結果として、コードを書くあらゆる環境で、一貫したナイトブルー系のファミリー体験が得られます。詳細な同期手順については、[ターミナル同期ガイド](/blog/codex-skin-terminal-sync/) をご覧ください。

## なぜこのファミリーがこれほどうまく機能するのか？

このパレットは、まずターミナルでの可読性を最優先に設計されています：前景色と深みのあるブルーグレー系背景との間に高いコントラストを確保し、互いに干渉しないよう配慮されたアクセントカラーを採用しています。こうした制約条件は、エディターへの適用にも自然と適合します。ファミリーが広範にわたって普及したのは偶然ではなく、最も厳しい表示環境（＝ターミナル）での可読性を前提に設計されており、それ以外の環境ではさらに容易に活用できるという、意図的な設計思想によるものです。

## よくある質問（Quick FAQ）

**Tokyo Night はダークモード専用ですか？**  
クラシック版はダークモードのみですが、より明るい「Storm」バリアントも存在します。本インデックスではダーク系のバリエーションを収録しています。

**どの Codex 移植版を選ぶべきですか？**  
まずは [Tokyo Night (CLI)](/skins/tokyo-night-cli/) を試してみてください。これはオリジナルに最も忠実な実装です。ややソフトなコントラストがお好みであれば、[Bearded](/skins/bearded-tokyo-night/) 版もぜひ検討してください。

**今後、同様のパターンをたどるパレットは増えるでしょうか？**  
ほぼ確実です。テーマエコシステムは常に、移植性の高い少数のファミリー（Tokyo Night、Monokai、Solarized、Dracula など）へと収束します。これらのファミリーを選択するのは、非常に安全な判断です。

**ターミナルと Codex のカラーマッチングはパフォーマンスに影響しますか？**  
一切ありません。すべて外見に関する設定であり、実行時オーバーヘッドはゼロです。

Tokyo Night ファミリーは、「一つのパレットが、あなたが使うあらゆるツールで生き続けられる」ことを証明しています。さっそく [Tokyo Night (CLI)](/skins/tokyo-night-cli/) を入手し、ターミナルの設定と同期させれば、ワークスペース全体が完全に統一されます。他の移植可能なファミリーを探すには、[フルスキンインデックス](/skins/) を閲覧するか、あるいは各ツールへの適用効率を比較した [エンジン比較記事](/blog/codex-skin-engines-compared/) をご覧ください。
