このインデックスで、2つのスキン詳細ページを開くと、「インストールプロンプトをコピー」ボタンと「テーマファイルをダウンロード」ボタンという、2種類の異なるインストールボタンが表示されます。これらは互換性がなく、その違いは多くの人が考えている以上に重要です。

この違いは以下の2つに分かれています：  
**プロンプトプリセット** は、Dream Skin などのエンジンが解釈可能な自然言語で見た目を記述したものであり、  
**テーマファイル** は、`.codedrobe-theme` や `.codextheme` のような構造化された仕様であり、確実かつ一貫して読み込まれます。それぞれについて、以下のように考えるとよいでしょう。

## プロンプトプリセットの動作原理

プリセットとは、たとえば「Clear Glass ライトテーマを適用 — クリーンでガラス調・低干渉のインターフェース」といった1文のことです。エンジンはこれを読み取り、事前に保存されたカラーパレットと照合して適用します。Dream Skin や同様のエンジンは、このモデルに基づいて動作します。

**強み：**  
- 現存する中で最も高速なインストール方法 — ペーストするだけで完了。  
- 人間が読める（自然言語）。説明文を編集すれば、バリエーションを簡単に得られます。  
- 探索に向いている。「少し暖かみを増して」というような指示も有効です。

**弱み：**  
- 解釈のばらつき。同じプロンプトでも、異なるエンジンによって異なる結果が出ることがあります。  
- 精度が低い。「ガラス調」は16進数の色値ではありません。  
- エンジン依存性が高い。プロンプトを理解できないエンジンでは、そのプリセットは意味を持ちません。

## テーマファイルの動作原理

テーマファイルとは、背景・前景・構文色・アクセント色など、すべての色を正確な16進数値で定義した仕様です。エンジンはそれを読み込み、ファイルに書かれた通りに厳密に適用します。`.codedrobe-theme`（codexskins.org などのギャラリーで使用）および `.codextheme` が代表的なフォーマットです。

**強み：**  
- 確定的（デターミニスティック）。表示される見た目は、ファイルに記述された内容と完全に一致します。  
- 同じフォーマットをサポートするエンジン間で、容易に移植可能です。  
- バージョン管理・差分比較・共有が容易 — 単なるテキストファイルだからです。

**弱み：**  
- 作成が遅い。すべての値を手動で正確に記述する必要があります。  
- フォーマットの断片化。`.codedrobe-theme`、`.codextheme`、CLI設定などは互換性がありません。  
- 編集にはフォーマットの知識が必要であり、「言い換え」だけでは不十分です。

## どちらが「優れている」のか？

目的に応じて異なります：

- **スピードと探索重視の場合** → プロンプトプリセットが優れています。5分で5種類のムードを試せます。  
- **一貫性と移植性重視の場合** → テーマファイルが優れています。ファイルは、どこで読み込んでも同じ意味を持ちます。  
- **バージョン管理重視の場合** → テーマファイルが圧倒的に優れています。プロンプトは自然言語であり、ファイルは差分比較可能な仕様です。

ほとんどのユーザーは、両者を併用します：まずプロンプトで好みの雰囲気を探し、その後テーマファイルでそれを固定します。

## 実践的な判断ルール

何かをインストールする前に、以下の質問を自分に投げかけてみてください：

1. すぐに見た目を試したい → プロンプトをコピー・ペーストすれば、即座に完了。  
2. 数か月以上使い続ける見た目が見つかった → 安定性・共有性のために、テーマファイルをダウンロード。  
3. 複数のマシンやチームで同期したい → テーマファイルを dotfiles リポジトリにコミット。  
4. バリエーションを試行錯誤したい → 「より暖かみを」という指示が、16進数の編集よりずっと速いので、プロンプトを使いましょう。

## よくある質問（Quick FAQ）

**プロンプトプリセットとテーマファイルで、まったく同じ見た目を再現できますか？**  
はい。プリセットエンジンの内部パレットが、テーマファイルの16進数値と一致していれば可能です。一部のエンジンでは、同一テーマに対して両方の形式が提供されています。

**どちらの形式が、エンジンのアップデートに強く耐えられますか？**  
一般的に、テーマファイルの方が強いです。フォーマットがサポートされ続ければ、仕様は有効であり続けますが、プロンプトはエンジンがその表現を引き続き理解できるかどうかに依存します。

**起動時の速度はどちらが速いですか？**  
ほぼ差異はありません。どちらもマイクロ秒単位で読み込まれる極小の設定ファイルです。

**このインデックスでは、どちらを推奨していますか？**  
各スキンの「インストール形式」フィールドをご確認ください — そこに適用される形式が明記されています。  
[Monokai Stone](/skins/monokai-stone/) と [Solarized](/skins/solarized/) は CLI／テーマ仕様として提供されています；  
[Clear Glass](/skins/clear-glass/) と [Vivid Purple](/skins/vivid-purple/) は、プロンプト対応型です。

一度両方を試せば、半日もあれば自分の好みがわかります。各形式の実例は [スキンインデックス](/skins/) でご覧になれます。まだ何もインストールしていない場合は、まずは [インストールガイド](/blog/how-to-install-codex-skins/) をご覧ください。
