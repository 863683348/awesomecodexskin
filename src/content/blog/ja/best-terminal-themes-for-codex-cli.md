Codex CLI のパレットは、あなたが一日中見つめ続ける画面です。そのため、デフォルト設定よりも深く考え、より適切な選択をする価値があります。本特集では、2026 年時点で Codex CLI 向けに利用可能な、インストール済みの構文パレットとして提供されている優れたターミナルテーマを、**可読性・目の疲れ・ターミナルとの相性**の 3 つの観点からランキング形式で紹介します。

## ランキングの評価方法

各テーマは以下の 4 つの基準で評価しました：

1. **コントラストと可読性** — コーディング中の前景色と背景色の分離度。
2. **目の疲れ** — 長時間の作業でも glare（まぶしさ）が少なく、負担が軽減されるか。
3. **ターミナルとの連携性** — 同じパレットが実際のターミナルテーマとしても存在するか。
4. **ロングテール性（長期間の支持）** — 時間の経過とともにその価値を証明してきたパレットか。

## 1. Tokyo Night — 総合トップのオールラウンダー

Tokyo Night（低まぶしさのダークブルー系パレット）が首位に選ばれました。純黒ではなく青みを帯びたダーク背景により、まぶしさが大幅に抑えられ、さらに構文色が細かく調整されているため、80 文字幅のプロンプト表示時や長いファイル一覧表示時にも十分な可読性を維持します。また、ターミナルおよび VS Code 向けの同名テーマも広く知られており、開発環境全体での統一が容易です。

## 2. Monokai Stone — 構文ハイライトに最適

Monokai Stone は、構文表示が重視される作業に最も適した定番テーマです。温かみのあるマuted（控えめな）背景色により、オリジナルの Monokai よりも強いコントラストを避けつつ、明るい構文色を十分に読み取れます。差分表示（diff）やソースコードの閲覧を日常的に行う方には、数分使うだけで「まさにこれだ」と感じられるパレットです。

## 3. Solarized — 長時間作業に最適

Solarized は、*Lab 色空間*に基づいて設計され、コントラストによる疲労を最小限に抑えることを目的としています。その結果生まれたマuted（控えめな）レトロ調パレットは、何時間続けても目に優しく、すべてのプラットフォーム（macOS / Windows / Linux）で対応するターミナルテーマも存在します。ただし、鮮やかな色彩を好む方にとっては、やや「インパクトに欠ける」可能性があります。

## 4. Vivid Purple — 個性を表現したい方に最適

CLI を「ただのデフォルト」ではなく、「自分らしさ」を感じさせるものにしたいなら、Vivid Purple がぴったりです。高彩度のパープルを基調としながらも、前景色のコントラストを十分に確保しており、快適な読書体験を損なわず個性を主張できます。気分転換やモード切り替え用の第 2 のテーマとしてもおすすめです。

## 5. Amber Nocturne — 温かみのあるダークテーマの最良選択

Amber Nocturne は、温かみのあるダークテーマの代表格です。柔らかなアンバー色の文字をダーク背景に配したこのパレットは、薄暗い部屋での使用時に、クールなブルー系テーマよりも目への負担が少なくなります。同様のアンバーカラーのターミナルテーマと組み合わせれば、統一感がありながらもレトロ・フューチャリスティックなワークスペースが完成します。

## これらのテーマのインストール方法

上記のすべてのテーマは、たった 1 行のコマンドで Codex CLI の構文パレットとしてインストールでき、その後 `/theme` コマンドで適用可能です：

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
/theme
```

## どのテーマを選ぶべきか？

- **デフォルト推奨**: Tokyo Night — 可読性とターミナル連携性のバランスが最良。
- **構文表示重視の作業**: Monokai Stone。
- **長時間作業または目の疲れが気になる方**: Solarized。
- **個性を重視する方**: Vivid Purple または Amber Nocturne。
