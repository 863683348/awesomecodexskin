The [Fei-Away Codex-Dream-Skin](https://github.com/Fei-Away/Codex-Dream-Skin) project — one of the most active open-source Codex skin engines — contributed 7 prompt presets to the index this week. If you've been curious about prompt-based skinning, this is a good moment to look.

## What's new from Fei-Away

The seven new presets show off the range of the Dream Skin engine, from clean professional looks to fully stylized themes:

- [Cyra Sacred Radiance](/skins/cyra-sacred-radiance/) — a luminous, light-leaning theme.
- [Dasiming Soul Passage](/skins/dasiming-soul-passage/) — a dark, atmospheric option.
- [Jensen Infinite Compute](/skins/jensen-infinite-compute/) — a tech-styled palette.
- Plus four more covering the spectrum between them.

All seven install with the Dream Skin method: copy the prompt, paste into Codex, done. The [engines comparison](/blog/codex-skin-engines-compared/) explains why that's the fastest install path in the ecosystem.

## The wider engine roundup

Beyond Fei-Away, a few things are moving in the engine world:

- **Codepilot** keeps shipping TUI improvements — validation and palette export are the headline features. See the [CLI comparison](/blog/codex-themes-cli-vs-codepilot/) for how it stacks up.
- **Codex Themes CLI** (ychampion) continues porting terminal classics; the Tokyo Night ports in this index come from that line.
- **Bearded Theme Ports** (vufly) added more tmtheme imports, which is how terminal themes like Tokyo Night keep flowing into Codex.

## Why prompt presets matter

Presets are the "try it in five seconds" path. Instead of downloading a file and configuring an engine, you paste one sentence. The tradeoff is precision — a prompt is a description, not a spec — which the [format comparison](/blog/codex-theme-file-vs-prompt-preset/) covers in depth. For exploring moods quickly, nothing beats it.

## How to try Dream Skin presets

1. Open a preset skin's page — [Cyra Sacred Radiance](/skins/cyra-sacred-radiance/) or [Dasiming Soul Passage](/skins/dasiming-soul-passage/) work well.
2. Copy the install prompt.
3. Paste it into Codex with the Dream Skin engine active.
4. Done — switch back to the default preset whenever you want.

The engine ecosystem is settling into a clear shape: prompt engines for speed, file-based managers for precision, CLI tools for terminal users. Each new contribution like this Fei-Away batch makes the ecosystem a little more complete. Browse the [skin index](/skins/) to see all the new presets.
