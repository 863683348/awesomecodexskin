霓虹赛博朋克类别是 Codex 主题彻底放弃“生产力”伪装、开始炫技的领域。这四个主题大胆采用高饱和度色彩：电光蓝、炽热粉、警示红、鲜活紫。如果你每天都要盯着编辑器看，那么一点视觉奇观不仅是合理特性，更是不可或缺的亮点。

该类别下恰好有四款皮肤，分为两大阵营：其中两款是桌面预设主题，可为整个 Codex 界面重新着色；另两款则是以语法高亮为核心、个性鲜明的主题。它们全都毫不含蓄，但彼此之间也绝非可以随意互换。

## 蓝色魅影：清爽的霓虹风

《蓝色魅影》（Blue Enchantress）出自 codexthemes.ai，是一款以蓝色霓虹为基调的画廊风格皮肤。它围绕单一主色调展开——一种明亮的电光蓝（#2D7DF6），其余配色则作为辅助色存在。最终效果既具赛博朋克气质，又不显杂乱无序。

这是本类别中最稳妥的选择。若你渴望霓虹视觉效果，却仍需连续八小时阅读代码，《蓝色魅影》便是那个始终清晰易读的主题。蓝色贯穿全局：语法高亮色在它衬托下跃然而出，而非与之冲突。

## 网络霓虹：抽象预设，真实出处

《网络霓虹》（Cyber Neon）源自 Codex Cidala Tiger Skin 仓库（MIT 许可协议），由用户 gh283248009 构建。它是一款引擎预设主题，即依托 Codex 主题引擎，在整个工作区统一应用霓虹赛博朋克风格。其锚点色为炽热粉（#FF2A6D）。

让《网络霓虹》脱颖而出的是其明确的来源。它是开源项目，代码仓库公开可查，你可在安装前通读预设源码。对重视所用软件透明度的用户而言，这是一项实实在在的优势。此外，它支持单行命令一键安装，部署成本几乎为零。

## 红白科幻：机甲线条与警示配色

《红白科幻》（Red-White Sci-Fi）由 Fei-Away 贡献，出自 Codex Dream Skin 项目。其描述精准到位：“机甲风格线条，搭配警示红与未来感白”。调色盘以 #E63946 为主导——这是一种工业感强烈、紧迫感十足的红色，而非浪漫主义的红。

这是本组中个性最鲜明的皮肤。它宛如出自巨型机甲维修舱的 UI 界面，因此若你希望编辑器自带驾驶舱氛围，《红白科幻》便是不二之选。代价在于：偏红的配色方案比蓝或紫色更易引发视觉疲劳，故更适合短时使用，或已钟情此风格的用户。

## 鲜艳紫（CLI 版）：原生终端主题

《鲜艳紫》（Vivid Purple）是本类别中的异类，正因如此更值得了解。它是一款紫色语法主题，由 vufly 从 Bearded Theme Ports 系列移植至 Codex CLI。其主色约为 #A020F0，并以 tmtheme 格式发布，意味着它经由 CLI 主题管线安装，而非通过桌面预设引擎。

如果你通过终端运行 Codex，那么这就是你的霓虹选项。其余三款皮肤均面向桌面应用；而《鲜艳紫（CLI 版）》是唯一专为 CLI 主题系统构建的主题。对完全不使用桌面界面的用户而言，它便是自然之选。

## 四款主题如何抉择？

- 选择 **《蓝色魅影》**：若你需要霓虹风格，同时兼顾全天候编码的可读性  
- 选择 **《网络霓虹》**：若你倾向开源预设，且追求一行命令极速安装  
- 选择 **《红白科幻》**：若你钟爱驾驶舱式视觉体验，并愿意接受潜在的眼部负担  
- 选择 **《鲜艳紫（CLI 版）》**：若你常年驻守终端，却仍渴望霓虹色彩  

目前四款皮肤均已开放安装。[安装指南](/blog/how-to-install-codex-skins/)详解了预设与命令行两种安装路径；[CLI 与主题管理器对比](/blog/codex-themes-cli-vs-codepilot/)则说明了不同安装方式如何适配你的 Codex 运行方式。若霓虹风格不合你胃口，不妨参考 [最佳暗色 Codex 主题](/blog/best-dark-codex-skins/) 与 [最佳浅色 Codex 主题](/blog/best-light-codex-skins/) 榜单，那里汇集了整个主题库中更为沉稳的选择。
