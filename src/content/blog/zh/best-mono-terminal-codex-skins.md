“单终端”（mono-terminal）类别是 Codex 中最接近“零装饰”的一类主题。这类皮肤将编辑器视作终端：仅使用一种背景色、少量语法高亮色，其余一切元素均不喧宾夺主。对常年浸淫于命令行环境的用户而言，这种极简并非为简而简——而是一种功能性的选择。屏幕上颜色越少，你的视线就越快聚焦于关键内容。

本类别共包含五款皮肤，它们共享同一设计哲学：语法高亮色应是窗口中最醒目的元素，其余所有界面元素则须保持静默。

## Monokai Stone：经典、去饱和

Monokai Stone 是 Monokai 配色方案面向终端原生体验的一次重构。标志性的 Monokai 调色板以高对比度与强表现力著称；而 Stone 版本则在保留深色背景及辨识度极高的强调色基础上，大幅降低整体饱和度。

最终呈现的主题仍能让你一眼认出“这是 Monokai”——粉红色的字符串字面量、绿色的注释、黄色的关键字——但消除了原版中那种令人不适的刺眼感。它延续了你已有的肌肉记忆，只是边缘更柔和、更舒适。

如果你早已熟悉 Monokai，那么这是本类别中最平滑的升级路径；如果你从未尝试过 Monokai，那么这一版本正是让你初识其神韵、又免于视觉疲劳的理想入口。

## Solarized CLI：经色彩科学验证的调色板

Solarized 之所以闻名，正因其设计基于严谨的色彩科学，而非主观审美。Ethan Schoonover 精心选取了 16 种颜色，并严格控制其相对亮度值。正因如此，该主题能在差异极大的各类环境中始终保持可读性——无论是明亮的办公室、昏暗的房间，还是廉价显示器或高端专业面板。

CLI 变体完整继承了这一工程化基因，并将其精准适配至 Codex 界面。背景采用 Solarized 标志性的柔蓝灰（soft blue-gray），所有强调色亦严格维持在同一亮度区间，确保无任何元素突兀跳脱。

当然，取舍真实存在：与霓虹风格浓烈的主题相比，Solarized 确实显得内敛含蓄。而这恰恰是它的设计初衷——你用视觉冲击力换取的是长期一致性；对于持续数小时的深度工作而言，这无疑是一笔明智的交易。

## Tokyo Night（ychampion）：霓虹感，但有章法

Tokyo Night 最初作为 VS Code 主题诞生，后逐步发展为一个完整的主题家族。Codex 主题库中的 ychampion 变体，正是该家族中专为终端体验优化的成员。

如果说 Solarized 偏向沉静，Monokai Stone 偏向温润，那么 Tokyo Night 则营造出一种冷峻而略带电流感的氛围：深邃蓝黑背景、明快的青色与粉色点缀、紫色高亮。它是“单终端”类别中色彩最丰富的皮肤，但其克制之处在于布局逻辑——霓虹色仅用于语法高亮，绝不会侵入界面边框（chrome）区域。

若你渴望极简皮肤带来的专注优势，却又觉得纯去饱和风格过于乏味，那么 Tokyo Night（ychampion）正是那个兼顾现代感与实用性的理想折中方案。

## Monokai Stone（CLI）：同套配色，终端原生优化

之所以单独提供标注为 CLI 的 Monokai Stone 版本，是因为同一套配色在不同加载方式下可能呈现差异。CLI 构建版专为嵌入终端环境的 Codex 体验而调优，确保其配色能与你实际使用的 Shell 颜色自然融合。

在 Monokai Stone 与 Monokai Stone（CLI）之间如何选择？取决于你运行 Codex 的方式：若你主要使用桌面应用并启用编辑器皮肤，首选标准版；若你大量使用面向终端的 UI 界面，则 CLI 版本可使配色与你的 Shell 环境保持一致。

## Codepilot 内置 TUI 皮肤：看似默认，实则精良

随 Codepilot 捆绑发布的内置 TUI 皮肤，常因“免费附赠”而被轻率忽略——这实属误解。它们正是“单终端”皮肤的参考实现典范：界面边框极简、语法层级清晰、毫无意外干扰。

它们同时也为整个类别设定了基准线。当你横向比较其余四款皮肤时，内置 TUI 外观即为中立参照点——“至少与默认一样简洁”，这本身便是一条合理且值得坚守的评判标准。

## 如何在五款皮肤中做出选择

- 若你熟悉 Monokai 并希望获得更柔和的体验 → **Monokai Stone**  
- 若你追求经科学验证、适合长时间工作的配色方案 → **Solarized CLI**  
- 若你倾向极简结构，同时期待现代感配色 → **Tokyo Night（ychampion）**  
- 若你通过终端运行 Codex → **Monokai Stone（CLI）**  
- 若你想要开箱即用、稳定可靠的默认选项 → **Codepilot 内置 TUI 皮肤**

全部五款皮肤均可通过 Codex 主题管理器一键安装。[终端同步指南](/blog/codex-skin-terminal-sync/)详细说明了如何保持 Shell 与编辑器配色的一致性——这一点在本类别中比其他任何类别都更为关键：唯有当环绕编辑器的终端环境也达成共识，“单终端”皮肤才能真正呈现出它应有的和谐与沉浸感。
