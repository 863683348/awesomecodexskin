# Codex 皮肤索引现已收录 103 款主题

线上索引里现有 103 款 Codex 皮肤，各自对应一个文件。这个数字来自 2026 年 10 月 30 日 main 分支下 `src/content/skins/` 目录里的 103 个 Markdown 条目。它不代表 103 次下载、正在使用的安装量，也不是推荐票数，只表示当前可以浏览的集合有多大。到了这个数量，问题已经变了：找一款主题很容易，决定先看哪四个页面，反而可能比安装花得更久。

## 103 款 Codex 皮肤究竟统计了什么

每个计入数字的项目，都是一个拥有独立 slug 和详情页的皮肤条目。CLI 版可以和桌面版并列存在，因为安装目标不同；有关联的配色也可能各有文件。博客文章和中文译文不会增加皮肤总数。

| 仓库中的项目 | 计入 103 吗 | 原因 |
|---|---:|---|
| `src/content/skins/` 里的文件 | 是 | 它会生成一个皮肤条目 |
| CLI 专用皮肤文件 | 是 | 它有独立的安装目标 |
| 介绍皮肤的博客文章 | 否 | 它属于编辑内容 |
| 博客的翻译文章 | 否 | 它翻译文章，没有新增皮肤 |

这个区别很实际，因为整数容易被误读成质量分。这里不是评分。有些条目是用途很窄的实验，有些则适合每天使用。

## Codex 皮肤分类在 103 款时怎么用

皮肤到了这个数量，Codex 皮肤分类比按字母浏览有用。已经确定要浅色界面的人，可以跳过角色主题；主要在终端工作的人，可以先看单色和 CLI 条目。分类标签负责第一次缩小范围，接着再用平台和安装格式继续筛。

如果风格名称看不出画面，按颜色找会更快。[蓝、紫、绿配色盘点](/blog/best-codex-skins-by-color-blue-purple-green/)按屏幕上真正出现的颜色组织选项。已经熟悉旧集合的读者，可以直接看[每月新入库页面](/blog/codex-skins-new-arrivals-monthly/)。

## 四款值得先试的 Codex 皮肤

下面四款值得先试的 Codex 皮肤只是起点，不是排名。它们通向不同方向，而且都在远端索引里有真实条目。

- [Clear Glass](/skins/clear-glass/) 从浅色界面开始，适合明亮房间。
- [Monokai Stone](/skins/monokai-stone/) 更克制，适合已经熟悉 Monokai 系列的人。
- [Cyber Neon](/skins/cyber-neon/) 是更响亮的暗色选择，强调色很容易看到。
- [Potion Workshop](/skins/codex-theme-potion-workshop/) 主题感更强，适合已经看腻中性配色的人。

先开两个，不用开十个。比较预览图、平台字段和安装方式。如果两个都不合适，就只换一个条件：浅色换深色、安静换装饰、桌面换 CLI。

## 怎样选择 Codex 主题，不浪费一晚上

怎样选择 Codex 主题，要从你真正使用的屏幕开始。画廊里好看的配色，放进一段很长的 diff 里可能很累；如果大部分工作都在终端完成，桌面皮肤也未必有用。

1. 按平时房间的光线选浅色或深色，不要照着产品截图选。
2. 确认条目支持桌面端、CLI，还是两者都支持。
3. 下载以前先看安装格式。
4. 用一项真实任务预览，例如 diff 或一段很长的命令输出。
5. 新主题完整用过一次工作时段以前，先保留旧主题。

[应用前预览皮肤的指南](/blog/how-to-preview-codex-skin-before-applying/)把试用步骤写得更细。

## 103 之后，Codex 皮肤索引还缺什么

103 之后，Codex 皮肤索引更需要清楚的排序，不需要急着追逐更大的数字。平台、分类和安装格式已经能去掉很多无关选项；统一的截图和更清楚的变体命名，会让剩下的选择更快。[99 款皮肤里程碑](/blog/codex-skin-index-hits-99/)记录了这次统计以前的集合状态。

现在可以把 103 当作一个实用的检查点。选择足够多，也已经多到值得认真筛选。先确定使用环境，再选颜色家族，找到一款顺手的就停下来。
