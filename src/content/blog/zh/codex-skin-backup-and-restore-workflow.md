Codex 皮肤备份这件事，平时没人做，直到真需要它的那一周。你重装了 Codex，或者一次更新把主题目录重置了，又或者换了第二台机器，那个花了一晚上调出来的配色就没了。主题本身往往还在磁盘某个角落，真正丢的是让它变成「你的」那些设置。

这篇讲完整的流程：要复制哪些东西、怎么导出 Codex 主题设置、重装后怎么恢复 Codex 皮肤，以及怎么让一套皮肤在多台机器之间保持一致。路径规则跟 [Codex 皮肤配置文件详解](/blog/codex-skin-configuration-file-deep-dive/) 里描述的一致。

## 一次 Codex 皮肤备份到底包含什么

主题文件只是其中一半。多数皮肤以 `.codedrobe-theme` 或 JSON 调色板的形式分发（格式拆解见 [Codex 皮肤文件格式说明](/blog/codex-skin-file-formats-explained/)），这部分很好搬。另一半是你的安装环境围绕它生成的状态：

| 项目 | 存放位置 | 能搬到另一台机器吗？ |
|---|---|---|
| 主题文件或调色板 | 皮肤目录，或导出的打包文件 | 可以 |
| 皮肤应用状态 | Codex 配置文件 | 可以，但路径可能要改 |
| 所用引擎 | 配置文件，或引擎自己的存储 | 部分可以 |
| 手工微调 | 取决于引擎放哪儿 | 只有引擎支持导出才行 |
| 终端同步 | 终端配置，不在 Codex 里 | 需要单独处理 |

最后一行最容易踩。如果你把配色同步进了终端，终端自己留了一份，Codex 的恢复不会碰它。这一份要单独同步，做法见 [让你的终端和 Codex 皮肤保持一致](/blog/sync-your-terminal-and-codex-skin/)。

## 怎么导出 Codex 主题设置

先导出，再动别的。现在花两分钟，好过以后照着截图重新拼一个配色。

1. 找到当前皮肤。`codex skin current` 会打印名字和它背后的文件，也可以在 [Codex 皮肤管理器](/blog/codex-skin-manager-guide/) 的画廊里从卡片上看。
2. 把主题文件从皮肤目录复制到一个你真的会备份的文件夹。
3. 只导出 Codex 配置文件里的设置部分，不要整文件复制。整份复制会带进一堆跟机器绑定的路径，后面全是麻烦。
4. 如果你用了引擎，也走引擎自己的导出。皮肤管理器有自己的库，Dream Skin 的预设是以提示词预设的形式存的。具体参数在 [命令速查表](/blog/codex-skin-command-cheat-sheet/) 里。
5. 记下是哪个引擎应用的。用 CLI 工具去恢复一个桌面端皮肤，是「恢复了却什么都没变」最常见的原因。

文件夹用皮肤名加日期命名。`clear-glass-2026-10-22` 比 `backup2` 强得多。

## 重装后怎么恢复 Codex 皮肤

这里顺序比速度重要。

- **先装，后恢复。** 把主题文件复制进一个还不存在的目录，Codex 一创建那个目录就会把它覆盖掉。
- **用导出时的那个引擎重新导入。** 哪个引擎出的，就回哪个引擎。
- **应用之前先修路径。** 打开导出的设置，把绝对路径换成这台机器上的路径。导入后毫无反应，基本都是路径指向了一个不存在的目录。
- **在真实会话里验证，别只看预览。** 预览只渲染配色，证明不了引擎确实应用了它。

如果恢复后只应用了一半，说明有别的东西在你之后又写了主题。两个应用器抢同一个文件是最常见的原因，[让多个 Codex 皮肤引擎共存而不冲突](/blog/run-multiple-codex-skin-engines-without-conflicts/) 讲了怎么摆平。如果你只是想从头来过，[如何卸载并重置 Codex 皮肤](/blog/how-to-uninstall-reset-codex-skin/) 里有干净的做法。

## 让 Codex 皮肤跨机器保持一致

两种做法，适合不同的人。

| 做法 | 搭建成本 | 适合谁 |
|---|---|---|
| 给导出文件夹做版本管理 | 低，一个 git 仓库 | 一台主力机，偶尔用第二台 |
| 用文件同步工具同步皮肤目录 | 最低 | 两台机器每天都用 |
| 每台机器从皮肤索引重新应用 | 几乎为零 | 临时环境，改动很少 |

如果你会改皮肤，导出文件夹那一套更合适。调色板一改你就有 diff，改坏了回滚一次就回来。实时目录同步搭起来更快，但它也会毫不犹豫地把一个错误同时推到所有机器上。

不管选哪个，把引擎设置排除在同步范围之外。A 机器装了皮肤管理器，B 机器可能只有 CLI，共用一个引擎值总有一台会失败。

## 常见问题

**Codex 把我应用的皮肤存在哪里？**
在 Codex 配置文件里；如果你用了皮肤管理器或 Dream Skin，引擎自己还存了一份。两处都复制。

**只有主题文件，重装后能恢复 Codex 皮肤吗？**
颜色能回来。引擎的微调和应用状态要用导出的设置才一起回来。

**备份能跨机器用吗？**
可以，前提是路径改成相对路径或重新指一遍。绝对路径就是导入后毫无反应的原因。

**多久备份一次？**
每次做了不想重做一遍的改动之后。现实一点说：常用的皮肤各备份一次，大改之后再补一次。
