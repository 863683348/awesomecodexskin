# 多显示器下的 Codex 皮肤配置

多显示器下的 Codex 皮肤会出现一种单屏环境永远暴露不出来的问题：你在笔记本上装好一款很满意的皮肤，把窗口拖到大屏上，同样的色值忽然变得发闷、偏暗，或者发白。主题文件没有任何损坏。两块面板对同一个颜色的呈现本来就不同，而大多数皮肤预览图都是在一台显示器、一种灯光条件下拍的。

解决方式很少是换一款皮肤。真正有用的是挑一款余量足够、能同时扛住两块面板的方案，再分别校准每一块屏幕。下面讲清楚接上第二台显示器后哪些东西真的变了、怎么据此选皮肤，以及怎样让终端和编辑器看起来仍像同一个工作区。

## 接上第二台显示器后，哪些东西变了

有四件事同时发生变化，其中只有一件是主题本身。

- 面板亮度和伽马不同：桌面显示器开到 80%，旁边的笔记本开到 45%，同一个中间调会呈现成两种颜色。
- 镀膜还会叠加一层。镜面屏提高饱和度，雾面屏把它压平，老一些的雾面面板伽马还常常跟不准。
- 混合缩放很常见：4K 面板开 150% 缩放，旁边 1080p 开 100%，同一个字重在一侧看起来更粗。
- 如果 Codex 窗口横跨两块屏幕，语法配色就等于在同一眼里对着两种环境光。

最后这一点解释了大部分抱怨。一款对着明亮墙面调出来的皮肤，当半个窗口挪到背光的窗前时，就会显得发浑。

## 按房间选皮肤，而不是按截图选

预览图在这件事上参考价值有限，它是在别人的显示器上做出来的。按你实际工作的光线来匹配皮肤，可以参照下面这张粗略的对照表。

| 你的环境 | 重点看什么 | 值得先试 |
|----------|------------|----------|
| 房间明亮、雾面屏 | 浅色背景配中间调正文，注释不要用浅灰 | [Clear Glass](/skins/clear-glass/)、[Berry（浅色日志）](/skins/berry-light-journal/) |
| 房间偏暗、深色桌面 | 整体亮度低，强调色之间拉开差距 | [Gothic Void Expedition](/skins/gothic-void-expedition/)、[Blue Enchantress](/skins/blue-enchantress/) |
| 某块屏幕背后有窗 | 中等饱和度，在明暗两端都站得住 | [Clear Glass](/skins/clear-glass/)、[Monokai Stone](/skins/monokai-stone/) |
| 副屏是 OLED 或 HDR | 避开纯黑背景，正文亮度高于纯白压低的层级 | [Berry（浅色日志）](/skins/berry-light-journal/)、[Clear Glass](/skins/clear-glass/) |

值得注意的规律是：中等饱和度的配色比高对比配色更能扛住双屏。极端值会把两块面板之间本就存在的差异进一步放大。

## 编辑器和终端保持同一套配色

双屏的编辑器主题还得和另一块屏上终端窗口里的那套对得上。如果编辑器用暖色深色调，终端用冷色调，你每次把视线移过去都要重新适应一次。

1. 先定桌面版皮肤，再从同系列里挑 CLI 变体。
2. 在皮肤详情页看平台标签。标着 `codex-desktop` 的皮肤不会影响 CLI。
3. 导出终端配色，把注释灰和编辑器的注释灰比对一遍。
4. 在真正要用的那块显示器上预览，再应用。

[终端同步步骤说明](/blog/codex-skin-terminal-sync/) 详细讲了导出那一步，[Codex CLI 与桌面皮肤的区别](/blog/codex-cli-vs-desktop-skins/) 解释了为什么有些配色根本没有对应的 CLI 版本。

## 最不起眼但最影响观感的部分：缩放与字重

多数多屏环境都是混合缩放。皮肤经常在这里替字体背了锅。

- 细体或 Light 字重在 4K 面板的 100% 缩放下会消失。先换成常规字重，再判断配色有没有问题。
- 行高低于 1.4 时，高像素密度屏幕上的语法高亮会明显更难读。
- 斜体注释在不同面板上渲染不一致，关掉它可以少一个没必要存在的变量。

对比度是另一半。[无障碍指南](/blog/codex-skin-accessibility-contrast/) 列出了值得达到的最低比值，[浅色与深色对比](/blog/light-vs-dark-codex-skins/) 里还有索引中每一组的实测数据。

## 一份只花十分钟的排查清单

1. 把两块显示器调到相同的白点，或者尽 OSD 所能接近。
2. 把偏亮的那块压下来，而不是把偏暗的那块提上去。
3. 安装一款中等饱和度的皮肤，分别在每块显示器上单独预览。
4. 把 Codex 窗口拖到两块屏幕的接缝处，检查有没有哪种颜色的可读性突然翻转。
5. 最后再做终端配色导出。晚改字体会让你刚做完的对比全部作废。

第 4 步最容易被跳过，而它恰恰能筛出那些再怎么预览都看不出来的皮肤。

## 常见问题

**两块显示器需要两套皮肤吗？** 只有当亮度差距很大时才需要。否则保留一套皮肤、逐块校准，比在桌面中间换一次配色读起来顺得多。

**为什么我的皮肤在外接屏上发灰？** 通常是亮度不匹配，或者镜面面板把黑点抬高了。先把偏亮的那块降下来。

**超宽屏会改变这些建议吗？** 会改变一点。单块屏幕面积越大，高对比配色越容易让你疲劳，所以中间调皮肤更耐看。
