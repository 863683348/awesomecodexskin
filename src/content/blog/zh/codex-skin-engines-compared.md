为 Codex 应用皮肤共有五种主流方式，它们的工作原理截然不同。选错一种，你可能要花数周时间与之搏斗；选对一种，换肤只需十秒。本文将这五种方式并列对比，助你一次阅读便做出选择。

## 五大引擎概览

| 引擎 | 支持平台 | 安装方式 | 最适合人群 |
|---|---|---|---|
| Codex Dream Skin | macOS、Windows | 通过代理提示词 / 预设 | 追求零配置的用户 |
| Codex Skin Manager | macOS、Windows | 内置图形化管理界面 | 偏好可视化选择器的用户 |
| ReTheme | macOS、Windows | 经签名认证的社区主题 | 追求精选、经审核主题的用户 |
| Codex Themes CLI | 跨平台 | 命令行 `/theme` 命令 | 终端使用者 |
| Codepilot | 跨平台（npm） | 内置 TUI `/skin` 命令 | 深度终端用户（“终端原住民”） |

## Codex Dream Skin —— “一键粘贴”方案

Dream Skin（源自 Fei-Away 项目，本索引中多个皮肤亦由其作者开发）可通过自然语言提示词安装皮肤。你只需复制一行类似“应用 Clear Glass 浅色主题”的指令，粘贴后引擎即自动应用对应配色方案。无需管理文件，也无需学习命令。

**优势：** 获取新外观的最快路径；预设已持久化存储，一键即可恢复默认设置。  
**劣势：** 精确性低于基于文件的主题——你是在描述一种视觉风格，而非加载一份明确定义的规范。

## Codex Skin Manager —— 可视化选择器

一款桌面端管理器，内置主题画廊：支持浏览、预览、启用与回滚。它最接近“皮肤应用商店”。如果你习惯先点击预览再决定是否采用，这就是为你打造的引擎。

**优势：** 启用前可实时预览；对非技术背景用户友好。  
**劣势：** 仅覆盖其自有画廊内容；导入第三方主题文件的操作比 CLI 工具更繁琐。

## ReTheme —— 精选认证方案

ReTheme 分发经数字签名的社区主题，意味着每个主题在抵达你之前均已通过人工审核。安全性更高、恶意或损坏文件风险更低，代价是主题库规模相对较小。

**优势：** 安全性与内容筛选兼备；签名主题可干净、无冲突地安装。  
**劣势：** 主题数量少于开源生态体系。

## Codex Themes CLI —— 终端经典方案

CLI 方式（例如 ychampion/codex-themes，该工具移植了 Tokyo Night、Monokai Stone 等主题）将皮肤视为一个可安装与切换的软件包，使用命令如 `/theme monokai-stone` 即可完成操作。它速度快、支持脚本自动化，并能无缝集成至你的 dotfiles 工作流。

**优势：** 支持脚本化；可纳入版本控制；工作流与其他 CLI 工具一致。  
**劣势：** 无内置可视化预览；对不熟悉终端的用户上手门槛较高。

## Codepilot —— TUI 功能完备型工具

Codepilot（可通过 npm 安装）提供一套完整的 TUI 主题管理器，支持 `/skin` 命令、主题校验、实时预览、回滚操作，以及终端配色导出功能。它是所有终端方案中功能最全面的一款。

**优势：** 校验、预览、回滚与配色导出集于一身；跨平台兼容。  
**劣势：** 相比纯 CLI 更复杂；若你仅需固定使用一个皮肤，则略显冗余。

## 该如何选择？

- **只想快速获得美观外观？** → 选 Dream Skin。  
- **偏好逐个点击预览后再决定？** → 选 Codex Skin Manager。  
- **重视经审核、带签名的主题？** → 选 ReTheme。  
- **常年驻守终端，需要脚本化能力？** → 选 Codex Themes CLI。  
- **追求功能最强大、一体化的终端工具？** → 选 Codepilot。

本索引所列全部皮肤均兼容上述五种引擎——大多数皮肤以提示词或主题文件形式分发，任一引擎均可直接使用。建议从你钟爱的皮肤入手，例如 [Clear Glass](/skins/clear-glass/) 或 [Gothic Void Expedition](/skins/gothic-void-expedition/)，再根据自身工作习惯选择匹配的引擎。

## 快速常见问题解答（FAQ）

**我可以同时运行两个引擎吗？**  
可以，但请指定其中一个是“活跃管理器”。若两个引擎同时写入预设配置，可能导致相互覆盖。建议选定一个为主力引擎，其余仅用于导入用途。

**各引擎是否兼容所有皮肤？**  
并非总是如此。基于提示词的引擎需要对应提示文本；基于文件的引擎则需匹配其支持的文件格式（如 `.tmtheme` 或 `codedrobe-theme`）。每个皮肤详情页的“安装格式”字段会明确标注其适配的引擎类型。

**哪个引擎拥有最大的主题库？**  
开源生态体系——包括 Dream Skin 的提示词库与 CLI 主题移植项目——拥有最庞大的主题数量，因其开放贡献机制；而精选型管理器虽主题数量较少，但安全性与可靠性更高。

请依据自身工作流而非流行度来选择引擎。随后，前往 [完整皮肤索引](/skins/) 浏览——每个皮肤的详情页均清晰标明其所支持的安装格式，从此再也不会下载错误的文件。若您初次接触 Codex 主题？欢迎从 [安装指南](/blog/how-to-install-codex-skins/) 开始。
