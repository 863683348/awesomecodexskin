# 最佳自然系 Codex 皮肤：3 款大地色主题

多数 Codex 主题都在把音量调大，nature-earthy 这个分类正好相反：它从苔藓、暮色和矿物颜料里取色，把界面留在安静的位置上。如果你每天要在编辑器里待六个小时，那么从这一组里挑一款自然系皮肤，通常就是到第五个小时还觉得舒服的那一种。分类下只有三款，彼此之间的重叠很少。

## 自然系分类解决的是什么问题

这里的配色逻辑来自户外，而不是屏幕。背景落在绿、褐、灰的区间里，强调色只从一个暖色或冷色来源取用，窗口框架不跟语法高亮争夺注意力。这一点比听起来更重要：主题的饱和度越高，你的视线就越容易反复回到窗口边框，而不是回到代码上。

代价是对比度。大地色系在对比强度上低于单色终端主题，所以如果你在采光很好的房间里工作，可能需要把显示亮度调高一档。

## Forest Mist：适合长时间专注的苔藓绿

Forest Mist 是 Cidala Tiger Skin 仓库里的一个雾林抽象预设，围绕一种柔和的绿（#4A6B52）构建，读起来是安静，而不是冷清。它适合那些一坐就是很久、并且希望窗口别再来讨关注的人。

它的情绪标签是 tranquil，这个描述很准。注释和字符串保持清晰，不会出现 Monokai 一类配色里那种亮粉或荧光绿。它也是这个分类里安装量较高的皮肤之一。

## Inspiration：适合深度工作的暖琥珀

Inspiration 内置在 Codex Dream Skin 引擎里，走向正好相反：以 #E0A23B 为核心的暖琥珀色，带一点进入心流时的光晕感。Forest Mist 是把房间调冷，这一款是把房间调暖。它更适合傍晚那段工作时间，那时绿灰色的背景容易显得发闷。

三款里它的安装量最高，一部分原因是它随 Dream Skin 一起分发。如果你已经在用这个引擎，这是零成本的选择。

## Kung Fu Women's Football：朱砂红与水墨

名字有些跳脱，配色却是认真的。Kung Fu Women's Football 把朱砂红（#C0392B）和水墨中性色放在一起，对比强度比另外两款更高。如果你喜欢大地色的思路，又觉得 Forest Mist 太安静，那么这款就是答案。

它还有一处实际区别：它是本图库中第一个通过机器校验的可安装主题，以真正的 .codedrobe-theme 文件分发，而不是提示词预设。

## 三款对照

| 皮肤 | 配色 | 平台 | 安装格式 | 适合场景 |
|------|------|------|----------|----------|
| Forest Mist | 苔藓绿 | Codex Desktop | 提示词预设 | 长时间专注 |
| Inspiration | 暖琥珀 | Codex Desktop（Dream Skin） | 提示词预设 | 傍晚、光线偏暗 |
| Kung Fu Women's Football | 朱砂红 + 水墨 | Codex Desktop | .codedrobe-theme | 想要大地色但对比更高 |

## 两步安装

1. 两款提示词预设：打开 Codex，运行 `/theme forest-mist` 或 `/theme inspiration`。
2. Kung Fu Women's Football：从 codexskins.org 下载 .codedrobe-theme 文件，在 Codex Desktop 中应用。

如果命令执行后界面没有变化，先确认 Dream Skin 是否处于启用状态，因为 Inspiration 这个预设由该引擎提供。

## 怎么选

- 希望工作时窗口彻底退到后面去 → **Forest Mist**
- 想要暖色调，而且已经在用 Dream Skin → **Inspiration**
- 喜欢大地色，但要求可读的对比 → **Kung Fu Women's Football**

## FAQ

**自然系皮肤比暗色霓虹主题更护眼吗？** 长时间使用通常是这样，因为饱和度更低。但它们的对比度并不更高，所以在光线充足的房间里要提高显示亮度。

**可以在 Codex CLI 上用吗？** 三款都面向 Codex Desktop。如果在终端里想要同样安静的感觉，Solarized CLI 最接近。

**必须安装 Dream Skin 吗？** 只有 Inspiration 需要。另外两款走各自的安装路径。

**大地色主题会影响语法高亮吗？** 配色改变的是背景与框架颜色，语法色仍然来自主题本身，需要特别留意注释的对比度。
