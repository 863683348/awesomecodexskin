# The Codex skin index now has 103 themes

103 Codex skins now have individual files in the live index. That number comes from the 103 Markdown entries under `src/content/skins/` on the main branch, counted on October 30, 2026. It does not mean 103 downloads, active installations, or endorsements. It is simply the current size of the browsable collection.

## What 103 Codex skins actually counts

Each counted item is a skin entry with its own slug and detail page. A CLI edition can sit beside a desktop edition because the install target is different. Blog posts and Chinese translations do not increase the skin total.

| Item in the repository | Included in 103? | Why |
|---|---:|---|
| A file in `src/content/skins/` | Yes | It produces a skin entry |
| A CLI-specific skin file | Yes | It has a separate install target |
| A blog article about a skin | No | It is editorial content |
| A translated blog article | No | It translates an article, not a skin |

Some entries are narrow experiments, while others work as everyday defaults.

## How Codex skin categories help at this size

Codex skin categories are now more useful than an alphabetical list. A visitor who knows they want a light surface can skip character themes. Someone working in a terminal can start with mono and CLI entries. The category label is a first cut, then platform and install format narrow the choice again.

## Four Codex skins to try before browsing all 103

These four Codex skins to try are starting points, not a ranking.

- [Clear Glass](/skins/clear-glass/) starts on the light side and makes sense in a bright room.
- [Monokai Stone](/skins/monokai-stone/) is the restrained option for people who already know the Monokai family.
- [Cyber Neon](/skins/cyber-neon/) is a louder dark choice when visible accents are useful.
- [Potion Workshop](/skins/codex-theme-potion-workshop/) is the themed pick for anyone bored by neutral palettes.

Open two, not ten. Compare the preview, platform field and install method. If neither feels right, change one variable: light to dark, quiet to decorative, or desktop to CLI.

## How to choose a Codex theme from 103 options

To choose a Codex theme without wasting an evening, begin with the screen you actually use. A theme that looks good in a gallery may be tiring in a long diff. A desktop skin may have no value if most of your work happens in a terminal.

1. Pick light or dark from your normal room, not from a product screenshot.
2. Check whether the entry supports desktop, CLI, or both.
3. Read the install format before downloading anything.
4. Preview one real task, such as a diff or a long command output.
5. Keep the old theme available until the new one survives a full session.

The [preview-before-applying guide](/blog/how-to-preview-codex-skin-before-applying/) covers the trial step in more detail.

## What the Codex skin index needs after 103

The next useful change to the Codex skin index is better sorting, not a race toward a larger number. Platform, category and install format already remove much of the noise. Consistent screenshots and clearer variant names would make the remaining choice quicker. The older [99-skin milestone](/blog/codex-skin-index-hits-99/) records where the collection was before this count.

For now, 103 is a practical checkpoint. It is enough choice to be interesting and enough clutter to reward a firm filter. Pick the environment first, then the colour family, and stop when one theme works.

## FAQ about 103 Codex skins

**Does 103 mean every palette is unrelated?** No. CLI editions and related variants can have separate entries because they install differently.

**Should I download several before choosing?** Two candidates are usually enough for a useful comparison. Test both on the same task.

**Will this article be wrong when another skin lands?** The total is a dated snapshot. The live directory can move past it at any time.
