La catégorie « néon cyberpunk » est celle où les thèmes Codex cessent de feindre la productivité pour passer à l’affichage spectaculaire. Ces quatre thèmes exploitent des couleurs saturées : bleus électriques, roses vifs, rouges d’alerte et violets intenses. Si vous passez vos journées à fixer un éditeur, un peu de spectacle constitue une fonctionnalité légitime — pas un bogue.

Il existe exactement quatre thèmes dans cette catégorie. Ils se divisent en deux groupes : deux sont des préréglages pour l’application de bureau, qui recolorient l’interface Codex dans son ensemble, tandis que les deux autres sont des thèmes axés sur la coloration syntaxique, dotés d’une forte identité visuelle. Aucun d’eux n’est discret, mais ils ne sont pas non plus interchangeables.

## Blue Enchantress : le néon épuré

*Blue Enchantress*, issu de codexthemes.ai, est un thème de galerie au bleu néon. Il repose sur une seule teinte dominante — un bleu électrique vif autour du code hexadécimal `#2D7DF6` — tandis que les autres couleurs de la palette jouent un rôle secondaire. Le résultat est un thème qui évoque le cyberpunk sans tomber dans le chaos.

C’est le choix le plus sûr de la catégorie. Si vous souhaitez l’esthétique néon tout en devant continuer à lire du code pendant huit heures, *Blue Enchantress* reste parfaitement lisible. Ce bleu agit comme un fil conducteur : les couleurs syntaxiques s’en détachent avec éclat, sans entrer en conflit avec lui.

## Cyber Neon : le préréglage abstrait, avec une véritable histoire

*Cyber Neon* provient du dépôt *Codex Cidala Tiger Skin* (licence MIT), développé par *gh283248009*. Il s’agit d’un préréglage moteur, c’est-à-dire qu’il s’appuie sur le moteur de thèmes de Codex pour appliquer un style cyberpunk néon à l’ensemble de l’espace de travail. Sa couleur ancrée est un rose vif, `#FF2A6D`.

Ce qui distingue *Cyber Neon* des autres thèmes de la catégorie, c’est son origine vérifiable. Il est open source, son dépôt est public, et vous pouvez consulter le code source du préréglage avant même de l’installer. Pour ceux qui tiennent à savoir précisément ce qu’ils exécutent, c’est un avantage réel. En outre, son installation se fait via une simple commande, rendant le coût de mise en place quasi nul.

## Red-White Sci-Fi : lignes mécha et couleurs d’alerte

*Red-White Sci-Fi* est une contribution de *Fei-Away*, issue du projet *Codex Dream Skin*. Sa description est limpide : « lignes mécha associées à un futurisme blanc et rouge d’alerte ». Sa palette tourne autour du rouge `#E63946`, une teinte qui évoque davantage l’industriel et l’urgence que le romantisme.

C’est le thème le plus expressif du groupe. Il rappelle l’interface d’un hangar à mechas, ce qui en fait un excellent choix si vous souhaitez que votre éditeur évoque un poste de pilotage. L’inconvénient ? Les palettes fortement teintées de rouge fatiguent plus rapidement les yeux que celles dominées par le bleu ou le violet ; ce thème convient donc mieux aux sessions courtes, ou aux utilisateurs qui apprécient déjà ce style.

## Vivid Purple (CLI) : l’entrée native pour terminal

*Vivid Purple* est l’élément atypique de la catégorie — et mérite d’être connu pour cette raison. Il s’agit d’un thème syntaxique violet, adapté à *Codex CLI* depuis la collection *Bearded Theme Ports* par *vufly*. Sa teinte centrale se situe autour du code hexadécimal `#A020F0`, et il s’installe sous forme de fichier `tmtheme`, ce qui signifie qu’il passe par le pipeline des thèmes CLI plutôt que par le moteur de préréglages pour application de bureau.

Si vous utilisez *Codex* depuis le terminal, c’est votre option néon. Les trois autres thèmes ciblent l’application de bureau ; *Vivid Purple* est le seul conçu spécifiquement pour le système de thèmes CLI. Il constitue donc le choix naturel pour ceux qui n’utilisent jamais l’interface de bureau.

## Comment choisir entre ces quatre thèmes

- **Blue Enchantress**, si vous recherchez un effet néon restant lisible sur une journée complète de travail  
- **Cyber Neon**, si vous préférez un préréglage open source installable en une seule ligne  
- **Red-White Sci-Fi**, si vous désirez l’esthétique cockpit et acceptez le compromis lié à la fatigue oculaire  
- **Vivid Purple (CLI)**, si vous travaillez exclusivement dans le terminal et souhaitez tout de même bénéficier de couleurs vives  

Les quatre thèmes sont installables dès maintenant. Le [guide d’installation](/blog/how-to-install-codex-skins/) couvre les méthodes basées sur les préréglages et les invites, tandis que la [comparaison CLI vs gestionnaire de thèmes](/blog/codex-themes-cli-vs-codepilot/) explique quelle méthode convient selon la façon dont vous utilisez *Codex*. Si le néon ne vous attire pas, les listes « coups de cœur » des thèmes [sombres](/blog/best-dark-codex-skins/) et [clairs](/blog/best-light-codex-skins/) explorent les versions les plus apaisantes de la bibliothèque.
