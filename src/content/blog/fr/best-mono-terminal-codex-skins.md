La catégorie mono-terminal est la plus proche de "sans décoration" que Codex ait. Il s'agit de thèmes qui traitent l'éditeur comme un terminal : un seul arrière-plan, quelques couleurs de syntaxe, et rien d'autre pour attirer l'attention. Pour les personnes qui passent leur temps dans la ligne de commande, ce n'est pas une minimalisme en soi — c'est un choix fonctionnel. Plus il y a peu de couleurs à l'écran, plus votre œil trouve rapidement ce qui compte.

Il y a cinq thèmes dans cette catégorie. Ils partagent une philosophie : les couleurs de syntaxe doivent être le point le plus fort dans la fenêtre, et tout le reste doit rester discret.

## Monokai Stone : le classique, désaturé

Monokai Stone est l'interprétation native du terminal du concept Monokai. La palette Monokai habituelle est haute en contraste et bruyante ; Stone réduit la saturation tout en conservant l'arrière-plan sombre et les couleurs de mise en évidence reconnaissables.

Ce que vous obtenez, c'est un thème qui ressemble immédiatement à "Monokai" — les chaînes en rose, les commentaires en vert, les mots-clés en jaune — mais sans la rudesse qui rend le thème original semblable à un cri.

C'est la même mémoire musculaire, mais avec des bords plus doux.

Si vous connaissez déjà Monokai, c'est le chemin d'amélioration le plus doux de la catégorie. Si vous ne l'avez jamais essayé, c'est la version qui vous donne l'idée sans la fatigue visuelle.

## Solarized CLI : la palette basée sur la recherche

Solarized est célèbre pour avoir été conçu sur la science des couleurs plutôt que sur le goût. Ethan Schoonover a choisi 16 couleurs avec une luminance relative précise, ce qui explique pourquoi le thème reste lisible dans des environnements très différents — bureau lumineux, pièce sombre, écran bon marché, panneau premium.

La variante CLI conserve cette qualité technique et l'applique à l'interface Codex. L'arrière-plan est le bleu-gris doux pour lequel Solarized est connu, et les couleurs d'accent restent dans la même bande de luminance, donc rien ne sort de place.

Le compromis est réel : Solarized peut sembler terne par rapport aux thèmes à dominante néon. C'est le but. Vous échangez le spectacle contre la cohérence, et pour de longues journées de travail, c'est un bon compromis.

## Tokyo Night (ychampion) : néon, mais discipliné

Tokyo Night a commencé comme un thème VS Code et est devenu une famille entière. La variante ychampion présente dans la bibliothèque Codex est le membre au style terminal de cette famille.

Alors que Solarized est modéré et Monokai Stone est chaud, Tokyo Night vise un état d'esprit froid, légèrement électrique : fond bleu profond, accents cyan et rose vif, mises en évidence violettes. C'est le thème le plus coloré de la catégorie mono-terminal, mais la discipline réside dans l'emplacement — le néon reste sur les couleurs de syntaxe et ne déborde jamais sur l'interface.

Si vous voulez les bénéfices de focus d'un thème minimal mais trouvez la désaturation pure ennuyeuse, Tokyo Night (ychampion) est le compromis qui semble encore moderne.

## Monokai Stone (CLI) : même palette, natif terminal

La version CLI de Monokai Stone existe parce que la même palette peut s'afficher différemment selon la manière dont le thème est chargé. La version CLI est optimisée pour l'expérience Codex intégrée au terminal, où la palette interagit avec vos couleurs de shell réelles.

Entre Monokai Stone et Monokai Stone (CLI), choisissez en fonction de la manière dont vous exécutez Codex. Si vous utilisez l'application de bureau avec le skin de l'éditeur, la version principale est la bonne. Si vous passez du temps dans l'interface orientée terminal, la version CLI maintient la cohérence de la palette avec votre environnement de shell.

## Thèmes TUI intégrés de Codepilot : le standard qui est vraiment bon

Les thèmes TUI intégrés qui accompagnent Codepilot sont faciles à ignorer car ils sont gratuits avec l'outil. C'est une erreur. Ils constituent l'implémentation de référence de ce qu'un thème mono-terminal devrait être : chrome minimal, hiérarchie de syntaxe claire, et zéro surprise.

Ils définissent également la base de toute la catégorie. Lorsque vous comparez les autres quatre thèmes, l'apparence TUI intégrée est le point neutre — "au moins aussi propre que le standard" est une norme juste pour tout thème mono-terminal.

## Comment choisir parmi les cinq

- **Monokai Stone** si vous connaissez Monokai et souhaitez quelque chose de plus doux
- **Solarized CLI** si vous voulez une palette basée sur la recherche pour de longues journées
- **Tokyo Night (ychampion)** si vous voulez une structure minimale avec des couleurs modernes
- **Monokai Stone (CLI)** si vous exécutez Codex via le terminal
- **Thèmes TUI intégrés de Codepilot** si vous voulez le standard qui fonctionne

Les cinq sont installables via le gestionnaire de thèmes Codex. Le [guide de synchronisation du terminal](/blog/codex-skin-terminal-sync/) explique comment garder vos palettes de terminal et d'éditeur alignées, ce qui est plus important dans cette catégorie que dans toute autre — un thème mono-terminal n'a de sens que lorsqu'il est en harmonie avec le terminal autour de lui.
