تتيح سمات Codex إعادة تخصيص واجهة OpenAI Codex Desktop وCodex CLI بحيث يتطابق المكان العمل مع ذوقك — لون داكن منخفض الإضاءة للجلسات الليلية، أو سطح بلون باستيل للنهار، أو مظهر نيون فقط للتسلية.

يغطي هذا الدليل كل الطرق لإعداد سمة Codex، من الرسالة التثبيت ذات النسخة الواحدة إلى مدير المواضع عبر CLI.

## الإصدار القصير

تُثبت معظم السمات على هذا المؤشر بنفس الطريقة:

1. اختر سمة وافتح صفحة التفاصيل الخاصة بها.
2. انسخ رسالة التثبيت (أو قم بتنزيل ملف المواطئ، بالنسبة للسمات التي تمثلها ملفات .codedrobe-theme).
3. الصق الرسالة في Codex Desktop أو أدخل الأمر في Codex CLI.
4. يقوم محرك المواطئ بتطبيق اللون فورًا — لا حاجة لإعادة تشغيل المحرك في معظم الحالات.

هذا كل شيء. السمات هي إعدادات، وليس كودًا، لذلك فإن تغييرها سريع وقابل للإلغاء.

## الطريقة 1: تثبيت عبر نسخ ولصق الرسالة (الأسرع)

تثبت معظم سمات Codex - وخاصة إعدادات المحرك من [Codex Dream Skin](https://github.com/Fei-Away/Codex-Dream-Skin)، محرك الإدخال المفتوح المصدر - من خلال رسالة طبيعية واحدة.

في صفحة تفاصيل أي سمة، يحتوي المربع **رسالة التثبيت** على تعليمات جاهزة للنسخ مثل:

```text
Codex، قم بتطبيق موضوع "Clear Glass" الفاتح — سطح نظيف خالي من التشتيت لمساحتي العمل.
```

انسخها، افتح Codex، وقم بلصقها. يقرأ المحرك الرسالة ويقوم بتطبيق اللون والحدود والألوان المميزة المحددة في الموضوع.

> **نصيحة:** إذا قام الرمز بتطبيق إعداد مسبق، سيحفظ المحرك الإعداد حتى يمكنك العودة إلى الافتراضي لاحقًا بضغط واحد.

## الطريقة 2: تنزيل ملف المواطئ (.codedrobe-theme)

بعض السمات تأتي كملف .codedrobe-theme قابل للتنزيل. بالنسبة لهذه السمات:

1. انقر على **تنزيل .codedrobe-theme** على صفحة السمة.
2. احفظ الملف في أي مكان مريح.
3. افتحه من Codex Desktop — تقوم المحركات المدعومة باستيراد المواطئ تلقائيًا.

هذه الطريقة شائعة على المواقع مثل codexskins.org التي توفر ملفات المواطئ الجاهزة.

## الطريقة 3: تثبيت سمة CLI باستخدام أمر

تستخدم سمات CLI في Codex مسار تثبيت مختلف. تتم عملية تثبيت السمات التي تستخدم تنسيق `tmtheme` (مثل موضوع Bearded Theme Ports) باستخدام أمر واحد:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
# ثم في Codex CLI قم بتشغيل:
/theme Tokyo Night
```

أدوات مثل [Codex Themes CLI](https://github.com/ychampion/codex-themes) و[Codepilot](https://github.com/charzhu/codepilot) تتعامل مع سمات CLI لك — تحقق من صحة، عرض مسبق، تطبيق، إرجاع، واستيراد ألوان واجهة سطر الأوامر المتطابقة.

## أي محركات تدعم السمات؟

| المحرك | المنصات | أسلوب التثبيت |
|---|---|---|
| Codex Dream Skin | macOS، Windows | رسالة نصية / إعداد مسبق |
| Codex Skin Manager | macOS، Windows | مدير مدمج |
| Codex Themes (السطح) | macOS | استيراد .codextheme |
| ReTheme | macOS، Windows | المواطئ المدعومة من المجتمع |
| Codex Themes CLI | متعدد المنصات | أمر CLI `/theme` |
| Codepilot | متعدد المنصات (npm) | واجهة TUI مدمجة `/skin` |

## كيف تتغير أو تستعيد سمة؟

- **محركات الإعدادات (مثل Dream Skin):** يحتفظ المحرك بالإعداد الافتراضي — عادةً ما يكون زر "استعادة الافتراضي" يعيد مظهرك الأصلي.
- **CLI:** الأمر `/theme` يعرض المواطئ المثبتة؛ قم بإعادة تشغيل الأمر باسم آخر لتغيير السمة.
- **ملفات المواطئ:** استيراد ملف .codedrobe-theme السابق أو إعادة تشغيل الإعداد الافتراضي للمحرك.
