يتطلب تغيير السمة في Codex CLI عملية مختلفة عن تلك المتبعة في Codex Desktop. فبدلًا من واجهة المستخدم المرئية، تقوم سمة Codex CLI باستبدال **لوحة ألوان الطرفية** — أي لون الخلفية، ولون المقدمة، وألوان التركيب النحوي — لضمان بقاء مُوجِّه الأوامر (prompt)، ووظائف الإكمال التلقائي، والمخرجات مقروءةً داخل الطرفية.

وفيما يلي سير العمل الكامل، بدءًا من الأمر الوحيد `/theme` الذي يُفعِّل التبديل الفوري، ووصولًا إلى تثبيت لوائح ألوان جديدة تمامًا.

## الطريقة الأسرع: الأمر `/theme`

يأتي Codex CLI مزوَّدًا بأمر داخلي مدمج للسمات. افتح مُوجِّه الأوامر واكتب:

```bash
/theme
```

وهذا يعرض قائمةً بكافة السمات المثبتة حاليًّا. استخدم مفاتيح الأسهم (أو اكتب اسم السمة مباشرةً) لتطبيق إحداها فورًا — دون الحاجة لإعادة التشغيل. فإذا كنت قد ثبَّت سمة تركيب نحوي مثل Tokyo Night، فستظهر في هذه القائمة باسمها الدقيق:

```bash
/theme Tokyo Night
```

## تثبيت لوحة ألوان جديدة أولًا

لا يعرض الأمر `/theme` سوى السمات المثبتة مسبقًا. أما لوائح الألوان التركيبية (مثل Tokyo Night وMonokai Stone وSolarized) فهي تُثبَّت عبر نص برمجي يقوم باستيراد اللوحة إلى دليل السمات الخاص بـ Codex CLI:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
# ثم اعرض القائمة وطبِّق السمة المطلوبة:
/theme
```

ويحتوي مستودع Bearded Theme Ports على أكثر من ٥٠ متغيرًا — من بينها Solarized وTokyo Night وMonokai Stone وغيرها — مما يمكِّنك من تجربة عدة لوحات ألوان خلال ثوانٍ معدودة.

## استخدام مدير السمات لاسترجاع الإعدادات ومزامنة الطرفية

إذا كنت تغيِّر السمات بشكل متكرر، فإن استخدام مدير سمات من سطر الأوامر يلغي الحاجة إلى التخمين:

- **Codex Themes CLI** (`ychampion/codex-themes`) — أداة سطر أوامر مكتوبة بلغة Go، تتيح لك **التحقق من صحة السمة، ومعاينتها، وتطبيقها، واسترجاعها إلى إصدار سابق، وتصديرها** كلوحة ألوان مطابقة إلى ملف تكوين الطرفية. طبِّق السمة باستخدام الأمر `codex-theme apply <name>`، وارجع إلى السمة السابقة بأمر واحد.
- **Codepilot** (`charzhu/codepilot`) — توزيعة خاصة بـ Codex CLI تتضمَّن واجهة مستخدم نصية تفاعلية (TUI) مدمجة:

```bash
npm i -g @charzhu/codepilot
# ثم شغِّل الأمر `/skin` داخل الواجهة التفاعلية لاختيار إحدى السمات الـ ١٦ المدمجة
```

## مطابقة الطرفية مع المحرر

تبدو لوحة الألوان في أفضل حالاتها عندما تشاركها الطرفية وواجهة سطر الأوامر والمحرر. وباستخدام Codex Themes CLI، يمكنك تصدير نفس الألوان إلى ملف تكوين الطرفية، بحيث تتطابق الطرفية مع Codex CLI بعد تطبيق السمة مرة واحدة فقط. ويمكنك دمج ذلك مع سمة محرر مُحوَّلة (مثل Tokyo Night في VS Code) لتحقيق بيئة عمل متناسقة تمامًا.

## استكشاف الأخطاء وإصلاحها

- **لا تظهر السمة في قائمة `/theme`**: نفِّذ نص التثبيت أولًا، ثم أعد فتح مُوجِّه الأوامر.
- **تبدو الألوان غير صحيحة بعد التبديل**: أعد تشغيل Codex CLI؛ إذ تقوم بعض الإصدارات المُحوَّلة بتخزين ألوان عند بدء التشغيل مؤقتًا.
- **تريد استخدام نفس لوحة الألوان في الطرفية**: استخدم خاصية التصدير في Codex Themes CLI لكتابة لوحة الألوان إلى ملف تكوين الطرفية.
