يُرجع الأمر `/theme` لا شيء، أو لا تتغيّر الألوان، أو يبدو لوحة الألوان خاطئة؟ تكمن مشاكل سمات واجهة سطر الأوامر Codex CLI عادةً في إحدى خمس أسباب. فيما يلي كيفية تشخيص كل منها وإصلاحه بالترتيب.

## ١. السمة غير مُثبَّتة (الأكثر شيوعًا)

يعرض الأمر `/theme` فقط السمات الموجودة في دليل السمات الخاص بـ Codex CLI. فإذا لم تُجرِّب تنفيذ أي نص برمجي للتثبيت من قبل، فستكون القائمة فارغة أو ستعرض السمة الافتراضية فقط.

**الحل:** ثبِّت لوحة ألوان أولًا:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
```

ثم أعد فتح موجه الأوامر ونفّذ `/theme` مرة أخرى — ويجب أن تظهر لوحة الألوان الجديدة باسمها الدقيق تمامًا.

## ٢. وجود ذاكرة مؤقتة قديمة للألوان عند بدء التشغيل

بعض الإصدارات الفرعية (ports) تقوم بتخزين الألوان مؤقتًا عند بدء تشغيل Codex CLI. وبعد تطبيق سمة ما، قد تبدو لوحة الألوان خاطئة حتى يتم إعادة تشغيل البرنامج في المرة التالية.

**الحل:** أعد تشغيل Codex CLI بعد تطبيق السمة، ثم نفّذ `/theme` مجددًا باستخدام الاسم نفسه. وإذا ظهرت لوحة الألوان الصحيحة، فهذا يعني أن المشكلة كانت في الذاكرة المؤقتة.

## ٣. عدم تطابق اسم السمة

يقوم الأمر `/theme` بمطابقة أسماء السمات بدقة تامة. فـ `Tokyo Night` ليست هي نفسها `tokyo-night` أو `TokyoNight`.

**الحل:** نفّذ `/theme` بدون أي وسيطات، ثم انسخ الاسم الدقيق من القائمة، وطبّقه حرفيًّا دون تغيير.

## ٤. ملف لوحة الألوان خاطئ أو ناقص

قد يكون ملف لوحة الألوان الذي تم نسخه من نص برمجي لنقل السمة غير مكتمل — مثل غياب مفاتيح الخلفية أو المقدمة أو التنسيق النصي. وفي هذه الحالة، تظهر الألوان غالبًا كإعداداتها الافتراضية مع تغيير واحد أو اثنين فقط.

**الحل:** أعد تشغيل نص التثبيت لجلب السمة الكاملة، أو استخدم مدير السمات للتحقق من صحة الملف:

```bash
# يقوم أدوات Codex Themes CLI بالتحقق من صحة لوحة الألوان قبل تطبيقها:
codex-theme validate <name>
codex-theme apply <name>
```

## ٥. عدم التزامن بين المحطة الطرفية (Terminal) وواجهة سطر الأوامر Codex CLI

إذا تطابقت إعدادات *المحطة الطرفية* بينما لم تتطابق إعدادات Codex CLI (أو العكس)، فهذا يعني أن كلا النظامين يقرآن ملفات تهيئة مختلفة. وتُعَد سمات واجهة سطر الأوامر مجرد لوحات ألوان — فهي لا تغيّر ملف تعريف المحطة الطرفية لديك.

**الحل:** صدّر نفس لوحة الألوان إلى كلا النظامين. ويمكن لأدوات Codex Themes CLI كتابة الألوان المطابقة تمامًا في ملف تعريف المحطة الطرفية، بحيث يؤدي تطبيق واحد إلى مزامنة كلا الواجهتين:

```bash
codex-theme export <name> --to-terminal
```

## ما زلت تواجه مشكلة؟

أعد التهيئة إلى حالة نظيفة: ألغِ تثبيت لوحة الألوان، وأعد التشغيل، ثم أعد التثبيت، وطبّق السمة باستخدام الاسم الدقيق تمامًا. وإذا كانت هناك مشكلة محددة في سمة معينة، فتصفح [فئة Mono & Terminal](/skins/category/mono-terminal/) للحصول على أحدث متغيرات لوحة الألوان، أو راجع [دليل سمات واجهة سطر الأوامر Codex](/blog/codex-cli-themes-guide/) لمعرفة خطوات التثبيت الكاملة.
