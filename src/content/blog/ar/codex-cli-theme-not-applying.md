`/theme` لا يرجع أي شيء، ولا تتغير الألوان، أو تبدو لوحة الألوان خاطئة؟ مشاكل قوالب Codex CLI شائعة في معظمها بسبب خمس أسباب. إليك كيف تقوم بتشخيص وتصحيح كل سبب على التوالي.

## 1. القالب غير مثبت (الأكثر شيوعًا)

يُعرض `/theme` فقط القوالب الموجودة في دليل قوالب Codex CLI. إذا لم تقم بتشغيل برنامج تثبيت أبدًا، يكون القائمة فارغة أو تظهر فقط الافتراضي.

**الحل:** قم بتثبيت لون أول:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
```

ثم أعد فتح النقطة وقم بإعادة تشغيل `/theme` — يجب أن تظهر اللوحة الجديدة تحت اسمها الدقيق.

## 2. ذاكرة التخزين المؤقت للألوان قديمة عند بدء التشغيل

بعض الإصدارات تخزن الألوان عندما يبدأ Codex CLI. بعد تطبيق قالب، قد تبدو لوحة الألوان خاطئة حتى إطلاق التالي.

**الحل:** أعد تشغيل Codex CLI بعد تطبيق القالب، ثم أعد تشغيل `/theme` بنفس الاسم. إذا ظهر القالب الصحيح، فإن ذاكرة التخزين المؤقت كانت السبب.

## 3. اسم القالب لا يتطابق

يتطابق `/theme` مع أسماء القوالب بشكل دقيق. `Tokyo Night` ليس هو نفسه `tokyo-night` أو `TokyoNight`.

**الحل:** قم بتشغيل `/theme` بدون معايير ونسخ الاسم الدقيق من القائمة، ثم قم بتطبيقه بشكل حرفي.

## 4. ملف لوحة ألوان خاطئ أو غير كامل

يمكن أن يكون القالب الذي تم نسخه من برنامج ترجمة غير كامل — يفتقر إلى الخلفية أو المقدمة أو مفاتيح الصياغة. هذا يظهر كألوان افتراضية في الغالب مع تغييرات واحدة أو اثنتين.

**الحل:** قم بإعادة تشغيل برنامج التثبيت للحصول على القالب الكامل، أو استخدم مدير لتأكيد الملف:

```bash
# Codex Themes CLI يؤكد اللوحة قبل تطبيقها:
codex-theme validate <name>
codex-theme apply <name>
```

## 5. عدم توافق终端 والCLI

إذا كان *النظام البيئي* متطابقًا ولكن Codex CLI لا يتطابق (أو العكس)، فإن الاثنين يقرأان إعدادات مختلفة. قوالب CLI مجرد لوحة ألوان — لا تغير ملف إعدادات نظامك البيئي.

**الحل:** قم بتصدير نفس اللوحة لكليهما. يمكن لـ Codex Themes CLI كتابة نفس الألوان في ملف إعدادات نظامك البيئي، لذلك يتم توسيق السطحين بمجرد تطبيق واحد:

```bash
codex-theme export <name> --to-terminal
```

## ما زلت عالقًا؟

استعد إلى حالة نظيفة: قم بإزالة القالب، أعد التشغيل، قم بتثبيته مجددًا، وقم بتطبيقه باسم دقيق. إذا كان هناك مشكلة مع قوالب معينة، تصفح الفئة [Mono & Terminal](/skins/category/mono-terminal/) للحصول على أحدث إصدارات اللوحات، أو تحقق من [دليل قوالب CLI](/blog/codex-cli-themes-guide/) للحصول على عملية التثبيت الكاملة.
