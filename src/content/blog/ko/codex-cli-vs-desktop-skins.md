Codex에는 두 가지 매우 다른 스킨 시스템이 있습니다: **Codex CLI 테마**와 **Codex Desktop 스킨**. 외관상으로는 유사해 보이지만(둘 다 작업 공간의 외관을 변경함), 내부 작동 방식은 완전히 다르며, 어떤 시스템을 선택할지는 Codex를 어떻게 사용하느냐에 따라 달라집니다.

## 간단히 정리하면

- **Codex Desktop 스킨**은 *애플리케이션 크롬*(UI 요소) — 사이드바, 테두리, 표면, 강조 색상 등을 변경합니다. 시각적으로 풍부하며, 설치는 설치 프롬프트나 테마 파일을 통해 수행됩니다.  
- **Codex CLI 테마**는 *터미널 색상 팔레트* — 배경색, 전경색, 구문 강조 색상 등을 변경합니다. 가볍고 이식성이 뛰어나며, 명령어로 설치하고 `/theme` 명령어로 적용합니다.  

데스크톱 앱을 사용한다면 Desktop 스킨을, 터미널에서 주로 작업한다면 CLI 테마를 선택하세요.

## 각 시스템이 변경하는 항목

| 항목 | Desktop 스킨 | CLI 테마 |
|---|---|---|
| 변경 대상 | 애플리케이션 크롬, 테두리, 강조 색상 | 터미널 색상 팔레트 |
| 설치 방법 | 복사-붙여넣기 설치 프롬프트 / 테마 파일 | 설치 스크립트 + `/theme` 명령어 |
| 시각적 풍부함 | 높음 (표면, 테두리 등 포함) | 낮음 (색상만 변경) |
| 이식성 | 데스크톱 엔진에 종속됨 | 모든 터미널 색상 팔레트와 호환됨 |
| 되돌리기 용이성 | 대부분의 엔진에서 한 번 클릭으로 복원 가능 | 다른 이름으로 `/theme` 명령어 재실행 |

## 귀하의 워크플로우에 맞는 선택은?

**Desktop 스킨을 선택하세요, 만약 당신이 다음 사항에 해당한다면:**
- Codex Desktop 앱을 주요 작업 공간으로 사용합니다.  
- 어두운 저조도, 파스텔, 네온, 애니메이션 스타일 등 전체적인 시각적 정체성을 원합니다.  
- 한 번의 클릭으로 복원 가능한 사전 설정된 테마를 선호합니다.  

**CLI 테마를 선택하세요, 만약 당신이 다음 사항에 해당한다면:**
- 주로 터미널 환경에서 작업합니다.  
- 셸과 Codex CLI가 동일한 색상 팔레트를 공유하기를 원합니다.  
- 버전 관리 가능하고 이식성이 뛰어난 구성 파일 형태의 테마를 선호합니다.  

## 두 시스템을 동시에 사용할 수 있나요?

네 — 서로 독립적입니다. 많은 사용자들이 앱에는 어두운 Desktop 스킨을, 터미널에는 일치하는 CLI 팔레트를 적용하여 전체 작업 공간을 하나의 통합된 시스템처럼 느끼도록 구성합니다. CLI 테마는 단순히 색상 팔레트이기 때문에 조합하기 쉽습니다: Tokyo Night, Monokai Stone, Solarized 등처럼 두 시스템 모두에서 제공되는 팔레트를 선택해 어디서든 동일하게 적용하면 됩니다.
