Codex CLI의 팔레트는 하루 종일 바라보는 표면이기 때문에 기본값보다 더 많은 고려가 필요합니다. 이 모음은 2026년에 Codex CLI에 최고의 터미널 테마를 정리한 것입니다 — 모든 테마는 설치 가능한 구문 팔레트로 제공되며, 가독성, 눈 피로, 그리고 터미널과의 호환성을 기준으로 평가되었습니다.

## 평가 방법

각 테마는 네 가지 기준으로 점수를 받았습니다:

1. **대비 및 가독성** — 코딩 중 전경과 배경 간의 분리.
2. **눈 피로** — 긴 세션에서 빛 반사 감소.
3. **터미널 호환성** — 동일한 팔레트가 실제 터미널 테마로 존재하는지 여부.
4. **내구성** — 시간이 지나도 유효한 팔레트.

## 1. 도쿄 나이트 — 전반적으로 가장 우수한 선택

도쿄 나이트(저조도 다크 블루 팔레트)가 목록에서 1위를 차지했습니다. 블루 틴트가 있는 어두운 배경은 순수한 검정색보다 조명을 줄이고, 구문 색상이 철저히 구분되어 80열 프롬프트와 긴 파일 목록 모두에서 가독성이 유지됩니다. 이 테마는 잘 알려진 터미널과 VS Code 버전이 있어 전체 설정에서 쉽게 동기화할 수 있습니다.

## 2. 몽코이 스톤 — 구문 강조에 최적

몽코이 스톤은 구문이 많은 작업에 대한 전통적인 선택입니다. 따뜻하고 억제된 배경은 원래 몽코이의 날카로운 대비 없이 밝은 구문 색상을 읽기 쉽게 해줍니다. 하루 종일 변경 사항과 코드를 읽는다면, 몇 분 후에 가장 "맞는" 팔레트를 느낄 것입니다.

## 3. 솔라라이즈드 — 장시간 사용에 최적

솔라라이즈드는 *lab 색상 공간*을 중심으로 설계되어 대비 피로를 최소화했으며, 여전히 효과가 있습니다. 퇴행적인 무채색 팔레트는 수 시간 동안 눈에 편안하며, 모든 플랫폼에서 터미널 테마로 존재합니다. 단점은 생동감 있는 색상이 선호된다면 덜 "돋보이는" 색상입니다.

## 4. 화려한 보라색 — 개성에 최적

CLI가 기본값처럼 느껴지지 않고 *당신의 것*처럼 느껴지고 싶다면, 화려한 보라색은 밝은 보라색 아이덴티티를 제공하면서도 읽기 편한 충분한 전경 대비를 유지합니다. 변화를 주기 위한 두 번째 테마로 매우 적합합니다.

## 5. 아머 노크턴 — 따뜻한 어두운 옵션

아머 노크턴은 따뜻한 어두운 선택입니다. 어두운 배경 위에 부드러운 아머 색상이 들어가서, 어두운 방에서 차가운 파랑 테마보다 눈에 덜 자극적입니다. 아머 터미널 테마와 함께 사용하면 일관되고 미래지향적인 작업 공간을 만들 수 있습니다.

## 이 중 어떤 것을 설치할 수 있습니까?

위의 모든 테마는 한 명령어로 Codex CLI 구문 팔레트로 설치되며, `/theme`을 통해 적용됩니다:

```bash
curl -fsSL https://raw.githubusercontent.com/vufly/bearded-theme-ports/master/scripts/install-codex.sh | sh
/theme
```

## 어떤 것을 선택해야 할까요?

- **기본 추천:** 도쿄 나이트 — 가독성과 호환성의 최선의 균형.
- **구문이 많은 작업:** 몽코이 스톤.
- **하루 종일 사용하거나 민감한 눈:** 솔라라이즈드.
- **개성:** 화려한 보라색 또는 아머 노크턴.
