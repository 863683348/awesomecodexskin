Codex 스킨을 직접 만드는 것은 예상보다 접근성이 높습니다. 대부분의 엔진은 배경, 표면, 텍스트, 강조 색상과 같은 작은 색상 집합으로 정의된 테마를 받아들입니다. Codex 앱 자체를 수정할 필요는 없습니다.

## 단계 1: 엔진 선택

테마 형식은 사용하는 엔진에 따라 달라집니다:

- **Codex Dream Skin** — 테마는 프리셋 또는 에이전트 프롬프트입니다. 시작하기 가장 쉬움: 팔레트를 한 문장으로 설명하세요.
- **Codex Skin Manager** — 시각적 선택기와 함께 테마 생성기를 제공합니다.
- **ReTheme** — 서명되고 업데이트 가능한 테마; 공개적으로 공유하려는 경우 좋습니다.
- **Codex Themes (데스크탑)** — `.codextheme` 파일이며, 생성기는 theme.codexguide.ai에 있습니다.

이 가이드에서는 프롬프트 방법을 사용할 것입니다(드림 스킨과 호환됨).

## 단계 2: 팔레트 선택

스킨은 주로 4~6가지 색상으로 구성됩니다:

| 역할 | 예시(라이트) | 예시(다크) |
|---|---|---|
| 배경 | `#F5F7FA` | `#0A0A0B` |
| 표면(패널) | `#FFFFFF` | `#16161A` |
| 텍스트 | `#1A1B26` | `#E4E4E7` |
| 강조 | `#2DD4BF` | `#2DD4BF` |

한 가지 강조 색상을 고수하세요. 너무 많은 강조 색상은 #1의 초보자 실수입니다.

## 단계 3: 프롬프트로 테마 작성

드림 스킨 프리셋은 단순한 설명문장일 뿐입니다:

```text
Codex, 커스텀 테마 적용 — 어두운 탄 회색 표면, 부드러운 아몬드 강조, 밝은 크림 텍스트를 가진 따뜻한 아몬드 해질녘 팔레트. 긴 읽기 세션에 적합한 조용하고 포근한 느낌.
```

엔진에 프리셋으로 저장한 후 테스트하세요. 결과가 의도와 일치할 때까지 단어를 반복하여 수정하세요.

## 단계 4: 실제 콘텐츠에서 테스트

결정하기 전에 바쁜 화면(긴 코드, 많은 패널)을 열어보세요. 어두운 테마는 스크린샷에서는 멋지게 보이지만, 패널 대비가 너무 낮아 실제 사용 시 실패할 수 있습니다. 확인하세요:

- 코드 에디터 가독성
- 사이드바/패널 구분
- 버튼과 링크에서 강조 색상의 가시성

## 단계 5: 공유하기

ReTheme 및 Codex Skin Manager와 같은 엔진은 테마를 내보낼 수 있습니다. 이 인덱스에 자신의 스킨을 제출하려면 [스킨 제출](/submit/) 페이지를 이용하세요 — 다른 사람들이 한 번 클릭으로 사용할 수 있도록 미리보기 이미지와 설치 프롬프트를 포함하세요.
