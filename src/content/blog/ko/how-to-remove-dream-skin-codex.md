Codex 드림 스킨을 변경하거나 다른 엔진으로 전환하려는 경우, Codex 드림 스킨을 제거하는 것은 간단하지만 *정확하게* 제거하는 것이 중요합니다. 반쯤 제거하면 현재 적용된 테마가 남아 있고, 다음 엔진과 충돌할 수 있습니다. macOS 및 Windows에서 올바르게 제거하는 방법을 알아보겠습니다.

## 시작하기 전: 먼저 활성 테마를 재설정하세요

드림 스킨이 현재 Codex 테마의 **활성 적용자**일 수 있습니다. 앱을 비활성화한 상태로 제거하면 사용자 정의 테마가 고정되고 관리할 수 없습니다.

1. 드림 스킨을 열고,
2. **기본값 복원**을 사용하여 Codex를 원래 모양으로 되돌립니다.
3. 계속하기 전에 Codex에서 기본 테마가 표시되는지 확인하세요.

다른 엔진인 [Codex 스킨 매니저](/blog/codex-skin-manager-guide/)로 이동하는 경우, 먼저 설치하고 새 활성 적용자로 설정한 후 드림 스킨을 제거해야 합니다. 이는 어떤 엔진도 테마를 변경할 수 없는 공백을 피할 수 있습니다.

## macOS에서 제거

1. 드림 스킨과 Codex 데스크탑을 종료하세요.
2. 애플리케이션에서 드림 스킨 앱을 쓰레기통으로 드래그하세요.
3. 잔여 구성 폴더를 삭제하세요 (존재할 경우): `~/Library/Application Support/Codex-Dream-Skin/` (또는 설치 시 사용한 정확한 폴더 이름).
4. 쓰레기통을 비우세요.

## Windows에서 제거

1. 드림 스킨과 Codex 데스크탑을 닫으세요.
2. **설정 → 앱 → 설치된 앱** (또는 컨트롤 패널 "프로그램 추가 또는 제거")을 통해 제거하세요.
3. 잔여 데이터 폴더가 남아 있다면 삭제하세요: `%APPDATA%\Codex-Dream-Skin` (또는 설치 시 저장한 위치).
4. 소스에서 설치했거나 패키지 관리자로 설치했다면 해당 제거 명령어를 실행하세요.

## 완전히 제거되었는지 확인하세요

제거 후 다음 사항을 확인하세요:

- Codex가 **기본 테마**를 표시해야 합니다 (이전에 활성 테마를 재설정했다면 그렇습니다).
- 드림 스킨 프로세스가 실행 중이지 않아야 합니다 (활동 모니터 / 작업 관리자 확인).
- 이제 두 번째 엔진이 적용자로 경쟁하지 않도록 해야 합니다 — 다른 엔진을 설치한 경우, 활성 엔진인지 확인하세요.

## 엔진을 바꾸려는 경우?

대부분의 사람들은 다른 것으로 전환하기 위해 드림 스킨을 제거합니다. 일반적인 두 가지 경로는 다음과 같습니다:

- **갤러리 UI로:** [Codex 스킨 매니저 가이드](/blog/codex-skin-manager-guide/)
- **CLI 테마로:** [엔진 비교](/blog/codex-skin-engines-compared/)는 Codex 테마 CLI 및 Codepilot과 같은 CLI 옵션을 다룹니다.

또한, 다른 *엔진* 대신 다른 *스킨*을 원한다면 [스킨 인덱스](/skins/)를 탐색하세요 — 엔진을 교체하는 것보다 스킨을 교체하는 것이 항상 더 빠릅니다.

## 빠른 FAQ

**드림 스킨을 제거하면 적용된 스킨이 삭제되나요?**
처음에 기본값으로 재설정했다면, Codex는 내장 테마로 돌아갑니다. 드림 스킨이 저장한 사용자 정의 프리셋은 앱과 함께 삭제됩니다.

**나중에 다시 설치할 수 있나요?**
네, 드림 스킨은 무료이며 오픈소스입니다. 공식 리포지토리에서 다시 설치하면 스킨 페이지의 안내사항이 여전히 작동합니다.

**드림 스킨을 제거하면 다른 엔진에 영향을 미치나요?**
아니요, 하지만 단 하나의 활성 적용자만 설치하여 마지막에 승리하는 충돌을 피해야 합니다.
