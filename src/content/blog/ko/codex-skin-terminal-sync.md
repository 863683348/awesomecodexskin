이전에는 어두운 Codex 스킨과 완전히 다른 터미널 팔레트를 함께 사용했습니다. 항상 탭을 전환할 때마다 눈이 약간의 이중 인식을 하곤 했는데, 배경색, 강조 색, 분위기가 모두 달라서 그런 것이었습니다. 그건 아무것도 아니었지만, 하루 종일 낮은 수준의 방해가 되었습니다.

해결책은 지루하지만 효과적입니다: **한 가지 팔레트, 모든 곳에서**. 동일한 색조 계열, 근접한 밝기, 동일한 강조 색. 이 페이지는 이 인덱스에 있는 CLI 테마에서 시작하여 터미널과 Codex 스킨을 동일한 팔레트로 설정하는 방법을 보여줍니다.

## 두 개의 아름다운 테마를 선택하는 것보다 동기화가 더 나은 이유

시각 시스템은 연속성을 선호합니다. 터미널, 에디터, 브라우저가 동일한 배경 톤과 강조 색을 공유하면, 패널 간 전환은 뇌에 거의 비용이 들지 않습니다. 충돌할 경우, 매번 전환은 작은 재정렬이 됩니다. 하루에 수십 번의 전환, 그리고 당신은 실제로 무의미한 집중력을 소비하게 됩니다.

두 번째 이점은 스크린샷과 페어 프로그래밍 세션에서 일관성 있게 보인다는 것입니다. "이게 같은 설정인가요?" — 네, 그것이 목적입니다.

## 두 세계 모두에 포함된 테마를 선택하는 쉬운 길

일부 팔레트는 도구 간으로 포팅되어 있으므로 동기화는 거의 무료입니다:

- **[Tokyo Night](/skins/tokyo-night-ychampion/)** — 원래 VS Code 테마였으나, 이 인덱스에서 Codex용으로 제공되며 Bearded 포트에서 [Tokyo Night (CLI)](/skins/bearded-tokyo-night/)와 같은 CLI 변형도 있습니다. 두 곳 모두 같은 야간 파란색 계열을 사용합니다.
- **[Monokai Stone](/skins/monokai-stone-cli/)** — 고전적인 Monokai 팔레트의 석회 회색 변형입니다. 널리 포팅되어 있어 일반적으로 터미널 에뮬레이터용 맞춤 설정을 찾을 수 있습니다.
- **[Solarized](/skins/solarized-cli/)** — 정확한 CIELAB 밝기 값으로 설계되어 앱 간에 일관된 렌더링이 가능합니다. 존재하는 가장 "모든 곳에서 동일한" 팔레트입니다.

이 중 하나를 선택하면 80%는 이미 완료됩니다: Codex 스킨을 적용하고, 터미널의 테마 선택기에서 동일한 팔레트를 찾아보세요.

## 손으로 직접 조정하는 방법: 4단계

당신의 좋아하는 Codex 스킨에 터미널 포트가 없는 경우, 직접 조정해야 합니다:

1. **스킨의 팔레트를 읽습니다.** 스킨의 상세 페이지를 열고, 색상 값이 여기에 나열되어 있습니다. 배경, 전경, 강조 색의 헥스 값을 기록하세요.
2. **터미널 테마 파일을 만듭니다.** 대부분의 에뮬레이터(iTerm2, Windows Terminal, kitty, WezTerm)는 단순한 헥스 기반 테마를 지원합니다. 매핑: 배경 → 터미널 배경, 전경 → 터미널 텍스트, 강조 → 터미널 커서/밝은 색.
3. **밝기를 가까이 유지합니다.** 색조를 정확히 일치시키지 말고, 터미널이 더 밝거나 어둡게 20% 이상 차이가 나는 것은 피하세요 — 눈이 이동을 느낄 수 있습니다.
4. **실제 세션에서 테스트합니다.** `ls`, git 로그, `vim`을 두 분간 실행해보세요. 배경 경계가 보이지 않는다면, 완료되었습니다.

## "충분히 가까운" 상태는 어떤 모습일까요?

완벽한 헥스 일치가 필요하지 않습니다. 동일한 배경 계열, 동일한 전경 온도, 동일한 강조 색 — 그것만으로도 충분합니다. [Monokai Stone (CLI)](/skins/monokai-stone-cli/)와 따뜻한 회색 배경의 기본 어두운 터미널은 함께 잘 어울립니다. 목표는 일관성, 즉 정체성이 아니라죠.

## 빠른 FAQ

**브라우저도 동기화해야 하나요?**
필요 없어요. 터미널 + 에디터 쌍은 눈을 이동시키는 대부분의 경우를 커버합니다. 만약 당신이 매우 깐깐하다면 브라우저 개발자 도구를 추가하세요 — 동일한 규칙이 적용됩니다.

**당신의 터미널 에뮬레이터는 사용자 정의 테마를 지원하지 않습니다.**
현대적인 것들은 모두 지원합니다. 만약 당신이 제한된 기업 환경에 얽매여 있다면, 터미널의 *기본* 팔레트와 일치하는 Codex 스킨을 선택하세요 — 역동기화도 가능합니다.

**동기화가 내 작업 속도를 늦출까요?**
아니요. 한 번의 구성만 필요합니다. 팔레트는 색상일 뿐이며, Codex 시작 또는 성능에 영향을 주지 않습니다.

[Tokyo Night](/skins/tokyo-night-ychampion/) 또는 [Monokai Stone](/skins/monokai-stone-cli/)를 가져와, 동일한 팔레트를 터미널에 적용하고, 당신의 눈이 받을 자격이 있는 휴식을 주세요. 기본 사항이 필요한 경우 전체 [스킨 인덱스](/skins/) 및 [설치 가이드](/blog/how-to-install-codex-skins/)가 있습니다.
